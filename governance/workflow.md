# Phase 01.5 — TradingView 盘面执行 Check（第 5 check，最重要）

> 此 check 是开仓前**入场位置精度**的最终把关，必须在 Maker 策略生成前完成。

数据来源：用户每日提供 TradingView BTCUSDT 15min 截图（Binance），含：
- VRVP（成交量分布）
- 用户手绘支撑/压力水平线
- 通道线（上升/下降通道）
- 交易宪法（图右，5 条不可违反）

判断逻辑：

* 价格在通道**边缘**（上沿被压 or 下沿获支）→ 入场位置优 → 可进入 Maker 策略
* 价格在通道**中部** → 入场位置不优 → **强制观望**（即使总评分 ≥ 70）
* 价格在 VRVP POC 密集区 → 额外减分，提高观望阈值

交易宪法强制条款（每次开仓前对照）：

1. 非系统不做
2. 非 Maker 不开
3. 违规即封禁交易资格
4. 浮盈首次 ≥ +1.5R 时浮盈防守层方可激活
5. 亏损砍短 盈利放满；**入场位置要求极高，否则胜率极低不符合系统**

# Phase 03 — Entry Qualification

允许交易条件：

* 总评分 ≥ 70
* 状态门禁通过
* 风控检核全部完成

否则：

强制观望。

# Phase 04 — State Gate

以下任意触发：

今日禁止交易。

* 情绪不稳定
* 节奏混乱
* 身体疲惫
* 连续止损 ≥ 3
* 强烈结果依赖

# Phase 05 — Risk Checklist

开仓前必须完成：

* 交易计划
* 风险敞口确认
* 技术面确认
* 止损止盈设置
* 时间窗口确认
* 入场信号确认
* 单笔亏损 ≤ 3%

缺失任意一项：

属于违规。
