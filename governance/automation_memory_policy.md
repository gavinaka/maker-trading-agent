# 自动化记忆隔离策略

本文件约束 Trading-System 生产自动化的宿主级 `memory.md`，其优先级不低于日报入口提示词。

## 允许保存

- 目标日期与 `slot`；
- automation gate / workflow lease 的机械状态；
- 当前阶段、错误代码、重试窗口；
- 产物路径、哈希和是否完成交付。

## 禁止保存

- 多空方向、市场判断和报告摘要；
- 盘口/盘面/总分、胜率或执行概率；
- 支撑、压力、入场、止损、止盈、撤单价；
- 仓位、订单、盈亏和 Maker 方案；
- 任何可在下一时段形成结论锚定的历史日报内容。

宿主会话可能在任务开始前自动注入自动化记忆，因此生产任务第一条机械命令必须运行 `runtime/automation_memory_guard.py`。发现污染时立即硬停，不得继续采集或分析。历史自动化记忆永远不是交易证据。
