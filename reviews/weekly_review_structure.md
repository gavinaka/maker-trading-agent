# 周报结构定义（图谱十九节）

> 本文件定义周报的**结构规范**。
> 模板渲染见 `templates/weekly_review.md`。
> Schema 见 `schemas/review_schema.json` → `weekly_review`。

---

## 核心信息

* **时点**：每周日 22:00
* **覆盖**：本周一至本周日（GMT+8 自然周）
* **文件命名**：`reviews/<YYYY-Www>_weekly.md`（如 `reviews/2026-W22_weekly.md`）
* **责任 Agent**：`review_agent`

---

### 三、洁净样本进度

- 累计 / 本周新增 / 进度 % / 违规笔数 / 主要违纪类型

### 四、总结

- 本周核心迭代
- 本周核心洞察

## 格式演化（图谱十九节）

### 早期格式（2025.6-9，AI 辅助期）
- ChatGPT 生成分析报告
- 概览数据 + 执行力评分表 + 盈亏结构 + 情绪行为分析
- 个人总结：手写 5-6 条具体经验教训
- 五维度评分表（★★★★☆格式）
- 使用 Binance

### 中期格式（2025.10-12，内化期）
- 简化为"四个核心问题复盘"
- 不再 AI 生成，完全个人书写
- 聚焦：计划完成度 / 交易闭环 / 左右侧权重偏移 / 心力状态
- 引入"第二关/第三关"心理关卡命名体系

### 当前格式（2026.1 至今，标准化期）
- 资金复盘 + 策略复盘 + 洁净样本进度 + 总结
- 三段式标准结构
- 与 check_records / state 文件联动
- 关键词体系命名

## 与日复盘的关系

```
日复盘 (reviews/<YYYY-MM-DD>.md) × 7
  ↓ 聚合（review_agent 周日 22:00）
周报 (reviews/<YYYY-Www>_weekly.md)
  ├─ 总笔数 / 胜率 = 7 日 check_records 聚合
  ├─ 浮盈浮亏 = 周末 state 快照
  ├─ 洁净样本贡献 = 7 日 clean_sample_eligible 计数
  └─ 关键洞察 = 用户从 7 日复盘中提取
```

---

## 禁止行为

* 禁止 AI 生成"核心迭代"/"核心洞察"
* 禁止跳过任一字段
* 禁止"现有资金"使用估算
* 禁止伪造或省略违规笔数
* 禁止覆盖历史周报
