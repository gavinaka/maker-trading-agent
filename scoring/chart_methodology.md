## 一、盘面的本质 + 🟥 两轴分离铁律

**盘面30 = 「盘面给出的机会质量 / 结构清晰度」，与方向、趋势完全无关。**

- 高分 = 位清晰 + 收割活跃 + 放量 + 共振叠加 = **机会质量高**，**不代表看多或看空**。
- **方向 / 趋势由「结构性趋势」字段（道氏，见三节）单独给。**
- 🟥 **铁律：严禁把高盘面分读成"看多/看空"。** 高分只证明位置清晰、结构活跃与机会质量高；多头、空头或震荡方向必须由独立结构链产生。
- 与盘口体系同构：盘口当前0–60=机会/极端度、signal_type=方向（schema中的70为未来原生结构化证明保留值且当前不可用）↔盘面30=机会/清晰度、结构性趋势=方向。

## 二、多周期结构 + 各级别职责（用户确认）

自上而下读，每级别各判各的：

| 级别 | TradingView 档 | 何时做 | 职责 |
|---|---|---|---|

## 三、趋势确认 = 道氏理论（用户新增 · 逐周期独立可冲突）

**判定法（道氏）：**
- **更高高点 + 更高低点 = 多头**
- 更低高点 + 更低低点 = 空头
- 否则 = 震荡（结构）

**两条要点：**
1. **逐周期各判各的，不同周期可以相反且同时成立**。例：1H/4H 出现 HH+HL = 多头趋势（短线），但日线相反 = 空头趋势（长线）——**短线多头与长线空头不矛盾**。
2. **尺度标签**标在括号里，指这个趋势在哪个尺度读出：
   - 1H / 4H（小时级别）→ **短线**
   - 日线级别 → **中线 / 中短线**
   - 周线级别 → **长线**

**🟥 日报输出口径：**
- 「结构性趋势 / 趋势确认」字段**只报短线 / 中短线**（可操作尺度），中线 / 长线作为背景写在解读正文里、不进该字段。
- **可并列双标签 = 主导方向 + 当前短线结构**：如「空头趋势 + 震荡结构（短线）」表示主导空头与当前短线震荡同时成立。两标签并存不矛盾，对应多周期可冲突。
- 支撑区间 / 压力区间 **均为日内**（见六节）。

## 四、5 项打分极致分档

### ① 支撑/压力接近度（0–10）— 看「位的清晰度 × 测试的活跃度」
- **10**：正在测试/跌破**多重共振**关键位（通道轨 + 可读的用户手绘成交量分布区域 + 0.618 叠加）。
- **8–9**：价格贴**单一明确**强压/强支并发生反应。
- **6–7**：接近次级位 / 测试但非决定性。
- **4–5**：区间中部偏一侧、位松散。
- **0–3**：区间正中、无明确位或证据不足。

### ② 多空流动性掠夺（0–10）— 看「候选止损池 × 用户手绘成交量分布 × 当前价格行为」
- **9–10**：价格正在高质量止损池边缘发生明确急扫/长 wick，且可读手绘区域支持该位置判断。
- **7–8**：显著接近或拿取一侧流动性，结构与价格行为一致。
- **4–6**：存在候选猎杀位，但位置质量、动作完成度或结构印证一般。
- **1–3**：仅有弱候选、震荡噪声或证据冲突。
- **0**：用户手绘区域不可读、没有可复核候选位，或证据不足。Coinglass 清算地图只能辅助印证，不能替代手绘区域、补分或翻向。

### ③ SMA20突破/回踩（0–5）— 🔑 看「价格是否正与 SMA20 交互」，**不是趋势强度**
- **5**：干净的 SMA20 事件——新鲜突破或回踩确认。
- **3–4**：与 SMA20 有意义交互。
- **1–2**：远离 or 缠绕、交互弱（多数日）
- **0**：**单边远离 SMA20**或本轮数值不可验证。
- ⚠️ **反直觉**：趋势越单边、价格越远离均线，本项反而可能为 0。**本项测「离 SMA20 多近、有无交互」，与日线把 SMA20 当趋势锚是两码事。**

### ④ 量价关系（0–3）
- **3**：放量强配合当前结构｜**2**：放量但结构配合一般｜**1**：平量｜**0**：缩量或证据不足。

### ⑤ 斐波/趋势线接近度（0–2）
- **2**：贴 0.618/趋势线/共振｜ **1**：附近｜ **0**：无

### 单边趋势日的「5 项指纹」
支撑压力↑（破关键位）+ 流动性↑（单边收割）+ 量价↑（放量）+ **SMA20↓=0（远离）**。

## 五、双重评分机制（用户确认）

- morning / midday / evening 每个 slot 各评一次。
- **3 次完全独立重评**：市场实时在变，**不沿用、不参考上一次**，按本 slot 当前结构活跃度重新评完 5 项。
- slot 间分差只表示市场结构随时间变化，不授权读取或对齐前一 slot 的分数。

## 六、日内支撑 / 压力（均为日内 · 15m 主参照）

- 支撑区间 / 压力区间 **一律日内**，必须用当次 TradingView 证据中的阿拉伯数字上下界表达；本方法文件不提供任何历史价格锚点。
- **主参照 = 15m**（点位精度 + 用户手绘成交量分布区域 + 用户手绘线），1H 辅助。
- 🟥 当前来源模式固定为 `user_drawn_manual_only`：只取用户图上**手绘支撑压力线 / 手绘成交量分布区域**，平台内置 VRVP 与自动 POC/VAH/VAL/HVN/LVN 数值禁止使用。区域必须用阿拉伯数字上下界表达，不臆造价位。

## 七、当前盘面校准程序

1. 每个 slot 从当前 TradingView 1D/4H/1H/15m 重新判定道氏结构、SMA20、量价、趋势线与手绘区域。
2. 5 项分数逐项绑定当前截图证据；缺少可读证据的分项不得沿用历史值或主观补分。
3. 盘面 30 只表达机会质量，不表达方向；结构方向由逐周期道氏链独立产生。
4. `user_drawn_manual_only` 是唯一 profile 政策：平台内置 VRVP 或自动 POC/VAH/VAL/HVN/LVN 点值不得进入。

## 八、元规则 / 禁止

- 🟥 **高盘面分 ≠ 方向 / 趋势**（双轴分离，一节）。方向只由道氏「结构性趋势」给。
- 🟥 **趋势 = 道氏（HH/HL · LH/LL），逐周期独立**；日报趋势确认字段只报**短线/中短线**。
- 🟥 **周线分析仅每周首个交易日做**；其余日不写周线。
- 🟥 **15m 仅服务日内 Maker**（精度/日内支撑压力/短周期价格行为），不进盘面30趋势打分。
- 🟥 **早/午/晚各自独立重评**，禁沿用上一次。
- 🟥 盘面30 数据源 = **TradingView 四档**（日/4H/1H/15m），缺一档=六源未齐=硬停；日内支撑压力取**手绘线/手绘成交量分布区域**、禁臆造价位。手绘成交量分布不可读只让该维度 `insufficient`，不阻断四周期结构。
- 单项给分必须可追溯到 TradingView 截图证据，禁主观加分。

## 九、流动性获取 / 猎杀底层逻辑

> 本节保存维护期已验收的抽象逻辑。运行期只使用本轮 TradingView 手绘区域与当前价格结构，不读取历史样本。
> 🟥 **三层语义勿混**：① **宏观资金流动性**（写「基本面」·缺失/未回归=利空背景）；② **时段流动性**（周末/休市薄→价格失真→观望·Maker 门控）；③ **结构性流动性获取/猎杀（本节·盘面 + Maker 挂价）**。

### A. 流动性 = 各周期的最高/最低点（止损池）
- 多周期（日/4H/1H/15m）各自的摆动高/低 = 候选猎杀位。
- 🟥 方向约定：**多头流动性 = 下方**（多头止损·价跌去取）；**空头流动性 = 上方**（空头止损·价涨去取）。

### B. 猎杀 = 概率，非时序
- 每个高/低点都是潜在猎杀位，只有**概率大小**之分——**不存在"领先/滞后确认"轴**。
- 猎杀动作 = 价格急速 overshoot / 长 wick 插针到该位之外、取走止损（视觉指纹：长 wick/急冲。5 类样本：低位插针取下方多头流动性／高位插针取上方空头流动性）。
- 🟥 取完后方向由**整体结构（道氏趋势 + 该位是否守住）**综合定，**不单凭插针预判反转**（守八节元规则 + judgment-synthesis-not-extreme：单变量不翻向、禁走极端）。

### C. 猎杀概率「主判」= 用户手绘成交量分布区域（当前来源政策）
- 底层逻辑不变：成交密集区域提供磁吸/反应概率，低量真空更容易直接穿越；它们只描述**位置与概率**，不直接给方向。
- 当前生产只允许 `user_drawn_manual_only`。平台内置 VRVP 必须隐藏且永不取值；自动 POC/VAH/VAL/HVN/LVN 单点数字禁止进入观察、评分、报告或 Maker 挂价。
- 手绘区域清晰可读时，以 `lower_bound–upper_bound + timeframe + role` 记录；只有用户图中明确标注时，才可把区域角色写成 `poc_zone`、`hvn_zone`、`lvn_zone` 或 `value_area`，仍不得压成自动单点。
- 手绘区域不可读、平台仍可见或状态未知时：`status=insufficient`、`zones=[]`、原因必填、`chart.liquidity_hunt=0`；禁止输出 POC/VAH/VAL/HVN/LVN 数值和任何猎杀概率落点。
- **多重共振**（极值 + 可读手绘成交量区域 + 0.618 + 趋势线）可提高位置质量；缺少手绘 profile 证据时不得由清算图补齐该共振。
- 📷 **读图来源**：每档 TradingView 的 `_liq` 文件名继续保留，但语义改为“用户手绘成交量分布/流动性区域特写”；它不是平台 VRVP 自动值截图。

### D. 「辅助印证」= Coinglass 清算热力图（② Coinglass 盘口/杠杆源的独立辅助通道 · 非新增核心源）
- 颜色 = 清算强度（**黄 = 最强磁吸**）；现价**上方亮带 = 空头流动性**、**下方亮带 = 多头流动性**；**阈值固定 0.85**。
- 🟥 周期规则：**周末（六/日）流动性极低 → 看 3 天**；**周一至周五 → 48H + 24H**。**跨周期持续出现的带 = 稳健磁吸；单周期闪现 = 噪声降级。**
- 🟥 **定位：只对 C 的概率做辅助印证**——与可读的用户手绘区域共振时抬高置信度，**不主判方向、不替代手绘成交量分布或四周期结构**。C 为 `insufficient` 时清算图只能保持 `neutral`，不得单独生成位置或概率。
- 🟥 **读位精度铁律**：清算带价位须对准纵轴网格/光标精确取价，并与 TradingView 手绘区域交叉核；禁止凭肉眼粗略估数或引用历史误差作为当前数值。
- 自动抓取：`node tools/browser_capture/capture_liqheatmap.js`（并入 `capture_all` 辅助源 · 周末3天 / 周中48H+24H · Binance BTC/USDT 永续 · 阈值0.85）。

### E. 落点（怎么用）
- **解读**：仅在手绘 profile `readable` 时，判断哪个周期的高/低点与手绘区域形成较高概率猎杀目标，作为方向背景而非方向盘。
- **Maker 挂价**：仅在手绘 profile `readable` 且其它独立证据闭环时，反弹空可参考上方高概率猎杀区域的边缘，低多止损可参考下方猎杀区域之外缘；`insufficient` 时不得由清算图或 Exocharts POC 补位。
- 与 §四① 支撑压力接近度打分**同源**（共振密度 → 分档）。

### F. 🟥 盘面节点深度推理步骤（插入日报工作流·见 daily-report SKILL §2）
读盘面时对"流动性猎杀"必走五步：
1. 标各周期（日/4H/1H/15m）摆动高/低 = 候选猎杀位；
2. 读取用户手绘成交量分布区域的上下界、周期与角色来判断猎杀**概率**；若不可读则明确 `insufficient`、该分项0分且不落概率位置；
3. Coinglass 清算热力图（周期按 D 规则）**辅助印证**、精确取价交叉核；
4. 仅在手绘区域 `readable` 时落「上方/下方最高概率猎杀**区间** + 阿拉伯数字上下界 + 周期标注」；`insufficient` 时不落位置或概率；
5. 喂给方向背景（B 节）与 Maker 挂价（E 节）。
> 🟥 报告写任何流动性区域**必带周期 + 阿拉伯数字上下界**；禁止把区间压成自动 POC/VAH/VAL/HVN/LVN 单点。profile 不足时必须明确证据不足且不得写概率位置。
