## 一、盘面的本质 + 🟥 两轴分离铁律

**盘面30 = 「盘面给出的机会质量 / 结构清晰度」，与方向、趋势完全无关。**

- 高分 = 位清晰 + 收割活跃 + 放量 + 共振叠加 = **机会质量高**，**不代表看多或看空**。
- **方向 / 趋势由「结构性趋势」字段（道氏，见三节）单独给。**
- 🟥 **铁律：严禁把高盘面分读成"看多/看空"。** 铁证：6/2 早 =24（强利空·单边空）与 5/24 晚 =23（震荡·中性）**同为高分、方向相反**。
- 与盘口体系同构：盘口70=机会/极端度、signal_type=方向 ↔ 盘面30=机会/清晰度、结构性趋势=方向。

## 三、趋势确认 = 道氏理论（用户新增 · 逐周期独立可冲突）

**判定法（道氏）：**
- **更高高点 + 更高低点 = 多头**
- 更低高点 + 更低低点 = 空头
- 否则 = 震荡（结构）

**两条要点：**
1. **逐周期各判各的，不同周期可以相反且同时成立**。例：1H/4H 出现 HH+HL = 多头趋势（短线），但日线相反 = 空头趋势（长线）——**短线多头与长线空头不矛盾**。
2. **尺度标签**标在括号里，指这个趋势在哪个尺度读出：
   - 1H / 4H（小时级别）→ **短线**
   - 日线级别 → **中线 / 中短线**
   - 周线级别 → **长线**

**🟥 日报输出口径（样本印证 + 30样本盲验）：**
- 「结构性趋势 / 趋势确认」字段**只报短线 / 中短线**（可操作尺度），中线 / 长线作为背景写在解读正文里、不进该字段。
- **可并列双标签 = 主导方向 + 当前短线结构**（30样本盲验发现）：如「空头趋势 震荡结构（短线）」= 主导空头（裸标签·常承日线）+ 当前短线为震荡；「多头趋势（短线） 震荡结构（打破）」同理。两标签并存不矛盾，对应多周期可冲突。
- 支撑区间 / 压力区间 **均为日内**（见六节）。

## 四、5 项打分极致分档（用户确认"完全正确"）

### ① 支撑/压力接近度（0–10）— 看「位的清晰度 × 测试的活跃度」
- **10**：正在测试/跌破**多重共振**关键位（通道轨+POC+VAL/0.618 叠加）。锚：6/2早、6/3早、6/1晚
- **8–9**：价格贴**单一明确**强压/强支并发生反应。锚：5/28晚、6/10晚、5/15早、5/18早
- **6–7**：接近次级位 / 测试但非决定性。锚：6/4、6/9、5/20
- **4–5**：区间中部偏一侧、位松散。锚：5/22早、5/31、6/11早
- **3**：区间正中、无明确位。锚：5/22晚

### ② 多空流动性掠夺（0–10）— 看「收割活跃度 × 单/双边 × 爆仓量能」
- **10**：单边大收割进行中（常伴爆仓）。锚：6/2早、6/3早、6/4(30亿爆仓拿多头流动性)
- **7–9**：显著收割/拿取。锚：5/28晚9、5/18早9、6/2晚9、5/29早8、6/1晚8、6/3晚7、6/10晚7
- **5–6**：中度。锚：5/27、6/8、5/19
- **2–3**：震荡、无明显收割。锚：5/26、6/1早、6/9、6/12
- **0–1**：缩量停滞。锚：5/22晚=0

### ③ SMA20突破/回踩（0–5）— 🔑 看「价格是否正与 SMA20 交互」，**不是趋势强度**
- **5**：干净的 SMA20 事件——新鲜突破 or 回踩确认。锚：5/15早晚=5（受SMA20放量反弹破M头）
- **3–4**：与 SMA20 有意义交互。锚：5/27=3、6/8晚=4、5/24晚=4
- **1–2**：远离 or 缠绕、交互弱（多数日）
- **0**：**单边远离 SMA20**。锚：6/2、6/3、6/4 单边暴跌=0
- ⚠️ **反直觉**：趋势越单边（如 6/2），价格越远离均线，本项反而 = 0。**本项测「离 SMA20 多近、有无交互」，与日线把 SMA20 当趋势锚是两码事。**

### ④ 量价关系（0–3）
- **3**：放量强配合方向（6/2、6/3早、5/28晚）｜ **2**：放量｜ **1**：平量｜ **0**：缩量（6/1早、6/9早、5/22早、6/12晚）

### ⑤ 斐波/趋势线接近度（0–2）
- **2**：贴 0.618/趋势线/共振｜ **1**：附近｜ **0**：无

### 单边趋势日的「5 项指纹」
支撑压力↑（破关键位）+ 流动性↑（单边收割）+ 量价↑（放量）+ **SMA20↓=0（远离）**。

## 八、元规则 / 禁止

- 🟥 **高盘面分 ≠ 方向 / 趋势**（双轴分离，一节）。方向只由道氏「结构性趋势」给。
- 🟥 **趋势 = 道氏（HH/HL · LH/LL），逐周期独立**；日报趋势确认字段只报**短线/中短线**。
- 🟥 **周线分析仅每周首个交易日做**；其余日不写周线。
- 🟥 **15m 仅服务日内 Maker**（精度/日内支撑压力/短周期价格行为），不进盘面30趋势打分。
- 🟥 **早/晚各自独立重评**，禁沿用上一次。
- 🟥 盘面30 数据源 = **TradingView 四档**（日/4H/1H/15m），缺一档=五源未齐=硬停；日内支撑压力取**手绘线/VRVP**、禁臆造价位。
- 单项给分必须可追溯到 TradingView 截图证据，禁主观加分。

## 九、流动性获取 / 猎杀 底层逻辑（用户核心标准 · 2026-06-21 锁定）

> 来源：用户 60 条手写 Plan 样本（2025.9–2026.6）+ 5 类 TV 视觉样本 + 3 张 Coinglass 清算热力图，经用户逐条审阅确认。
> 🟥 **三层语义勿混**：① **宏观资金流动性**（写「基本面」·缺失/未回归=利空背景）；② **时段流动性**（周末/休市薄→价格失真→观望·Maker 门控）；③ **结构性流动性获取/猎杀（本节·盘面 + Maker 挂价）**。

### A. 流动性 = 各周期的最高/最低点（止损池）
- 多周期（日/4H/1H/15m）各自的摆动高/低 = 候选猎杀位。
- 🟥 方向约定：**多头流动性 = 下方**（多头止损·价跌去取）；**空头流动性 = 上方**（空头止损·价涨去取）。

### B. 猎杀 = 概率，非时序
- 每个高/低点都是潜在猎杀位，只有**概率大小**之分——**不存在"领先/滞后确认"轴**。
- 猎杀动作 = 价格急速 overshoot / 长 wick 插针到该位之外、取走止损（视觉指纹：长 wick/急冲。5 类样本：低位插针取下方多头流动性／高位插针取上方空头流动性）。
- 🟥 取完后方向由**整体结构（道氏趋势 + 该位是否守住）**综合定，**不单凭插针预判反转**（守八节元规则 + judgment-synthesis-not-extreme：单变量不翻向、禁走极端）。

### C. 猎杀概率「主判」= TV 成交量结构（VRVP / VAL / VAH / POC）
- **POC（最大成交量价位）= 磁吸中枢**：价远离 POC → 回归概率高 → 远端高/低点 = 高概率目标。
- **VAH / VAL（价值区上下沿）= 反应边界**：落其上的极值 = 高概率猎杀 + 反应位。
- **VRVP 节点**：HVN 高量 = 高概率有效猎杀；**LVN 低量真空 = 低概率**（价易直接穿越不停留）。
- **多重共振**（极值 + POC + VAH/VAL + 0.618 + 趋势线）= **最高概率** = 本文 §四① 「支撑/压力接近度」**10 分**档（同源）。
- 📷 **读图来源**：每档 TV 的 `_liq` 高低点+VRVP 特写图（`capture_tv.js` 每周期第②张·把摆动高/低 + POC/VAH/VAL 放大到精确可读）；🟥 用特写图**精确取价、禁 eyeball**。

### D. 「辅助印证」= Coinglass 清算热力图（③Coinglass 盘口/杠杆源 · 非新增第六源）
- 颜色 = 清算强度（**黄 = 最强磁吸**）；现价**上方亮带 = 空头流动性**、**下方亮带 = 多头流动性**；**阈值固定 0.85**。
- 🟥 周期规则：**周末（六/日）流动性极低 → 看 3 天**；**周一至周五 → 48H + 24H**。**跨周期持续出现的带 = 稳健磁吸；单周期闪现 = 噪声降级。**
- 🟥 **定位：只对 C 的概率做辅助印证**——与 TV 成交量结构**共振时抬高置信度**，**不主判方向、不替代 VRVP/结构**。
- 🟥 **读位精度铁律**：清算带价位须对准纵轴网格/光标精确取价（曾肉眼误差 ~200 点）+ 与 TV 位交叉核，**禁 eyeball**，按精确数字写（见 `memory/precise-numbers-no-fuzzy.md`）。
- 自动抓取：`node tools/browser_capture/capture_liqheatmap.js`（并入 `capture_all` 辅助源 · 周末3天 / 周中48H+24H · Binance BTC/USDT 永续 · 阈值0.85）。

### E. 落点（怎么用）
- **解读**：定"哪个周期的高/低点是高概率猎杀目标"，作方向背景。
- **Maker 挂价**：反弹空挂**上方高概率猎杀磁吸的边缘**（见 `memory/rebound-short-highest-edge.md`）；低多 SL 放**下方猎杀位之外缘**（见 `memory/long-sl-outside-support-band.md`）。
- 与 §四① 支撑压力接近度打分**同源**（共振密度 → 分档）。

### F. 🟥 盘面节点深度推理步骤（插入日报工作流·见 daily-report SKILL §2）
读盘面时对"流动性猎杀"必走五步：
1. 标各周期（日/4H/1H/15m）摆动高/低 = 候选猎杀位；
2. VRVP/VAL/VAH/POC 读每个位的猎杀**概率**（HVN 高 / LVN 低 / 共振厚薄）= **主判**；
3. Coinglass 清算热力图（周期按 D 规则）**辅助印证**、精确取价交叉核；
4. 落「上方/下方 最高概率猎杀位 + **精确价位** + **周期标注**」；
5. 喂给方向背景（B 节）与 Maker 挂价（E 节）。
> 🟥 报告写任何流动性位**必带周期 + 精确价位**（`report_lint` 机械门强制·缺周期即 HARD FAIL）。
