# 交易评分系统

> **当前vNext边界**：本文的“盘口70+盘面30=100”只表示schema名义容量。当前production盘口只允许0–60，61–69非法，70为未来原生结构化证明保留值且不可由配置单独启用；因此当前有效总分最高90。当前运行以`scoring/scoring_contract.json`、`orderflow_methodology.md`和`score_thresholds.md`为准。

# 总评分结构
评分schema名义容量 = 盘口70 + 盘面30 = 100；当前production有效值域 = 盘口0–60 + 盘面0–30，总分最高90。

---

# 开仓门槛

## 标准规则（双硬门槛·并列共存·任一不满足即不开）
* 总评分 ≥ 65分
* **且** 胜率（自估）≥ 60%（2026-06-16 升级为硬门槛）
* 两者全满足才允许开仓；入场价格触达概率 ≥50% 仅为软参考、非门槛、不决定是否开仓，且不是实际成交概率

极端候选：
CVD上升、价格下降、持仓上升或横盘、资金费率为正值，只构成看跌极端候选；当前仍须在0–60内按完整证据落值，不代表必做。
CVD下降、价格上升、持仓上升或横盘、资金费率为负值，只构成看涨极端候选；当前仍须在0–60内按完整证据落值，不代表必做。

# 系统核心原则
评分系统高于主观判断，高于情绪，高于临时感觉。

---

# 评分用途
评分系统用于：
* 判断是否允许开仓
* 判断是否观望
* 判断市场结构质量
* 判断风险收益结构
* 判断系统一致性

---

# 评分结果逻辑

## 高评分
代表：
* 市场结构清晰
* 共振度高
* 风险收益比合理
* 系统一致性较强

## 低评分
代表：
* 市场结构混乱
* 方向不明确
* 风险收益比不足
* 不满足系统要求

---

# 核心原则
宁可错过，不能乱做。

---

# 强制规则
评分未达65，禁止寻找主观理由强行交易。
