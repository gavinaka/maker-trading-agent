# 胜率自估方法论（开单硬门槛② 的可复算 rubric）

> 权威：系统自估"胜率"的唯一口径。胜率＝**开仓前的前瞻确信度分级**（plan-time conviction），**非回测命中率**。
> 来源：2026 年 1–5 月用户真实样本 55 个倒推归纳（详见 `outputs/2026_胜率判断分析.md`）。
> 接口：本方法论产出的胜率喂入 [开单双门槛](score_thresholds.md) 的 **门槛②（胜率 ≥60%）** 与 `agents/risk_agent.md` Gate5。

---

## 0. 定位（三轴分离·勿混淆）
- **胜率＝设置质量/确信度**（本文件·开单硬门槛②）。
- **执行概率＝价格可达性**（软参考·非门槛·见 `score_thresholds.md`）。
- **盈亏比＝独立要求**（恒 ≥1:2.5）。
- 三者**互相独立**：同一胜率档执行概率可 50%–80%；高胜率不代表高可达。**禁把执行概率/盈亏比当胜率、禁把胜率当命中率。**

## 1. 锚点事实（不可违反）
- 🟥 **胜率词汇只有 `70 / 75 / 80`**（极高确信反转单偶到 85）；**实际开单从不低于 70**。
- 🟥 **自估 <70 ＝ 确信不足 ＝ 观望不开单**（不存在"开一笔 60-69 的单"）。门槛②的 60% 是地板表述，落地档位即 70 起步。
- 55 样本分布：70＝53% / 75＝24% / 80＝24%。
- 含义：胜率档的真正作用＝**确信度地板 + 质量分级**；系统达不到"70 档质量"就该落观望。

## 2. 两大主因 + 次因
- **主因①：盘口信号确认强度** —— 明确背离/极端组合 > 小幅/4H 背离 > 纯中性。
- **主因②：结构位质量** —— 多重强共振关键防守位 > 普通高质量边缘 > 一般达标边缘。
- **次因（只微调档位、不单独定档）**：盈亏比（1:3/1:3.5 偏高档）、顺/逆势（逆势单确信偏低）、事件窗口（数据公布前不确定→压低或观望）。

## 3. 三档 rubric（自估按此映射）

| 自估 | 触发条件（挂现有评分体系因子） | 真实样本锚点 |
|---|---|---|
| **<70 → 观望** | 盘口纯中性无背离 + 无高质量边缘；或高波动事件前（CPI/非农/利率决议）不确定；或 R:R<2.5；或超跌结构未企稳 | 64 个观望日（"胜率及盈亏比不符合系统要求"） |
| **70**（baseline·达标确信底） | 共振结构达标 + **盘口解读＝中性/中性偏多/中性偏空（无明确背离）** + R:R≥1:2.5 + 合理边缘 | 3.18 高空(中性·多头短线)、2.18 低多(中性·空头趋势)、1.16 回调多(中性·多头中线)、5.6 高空(中性·多头单边逆势→仅给底档) |
| **75**（中等加成） | 70 基础上**多一项确认**：出现**小幅 / 4H 级别背离**，或**结构位质量更高 / R:R≥1:3** | 5.11 高空(看跌背离4H)、2.13 做多(持续看涨背离)、4.1 低多(小幅看涨背离)、1.7 高空防守(小幅看跌背离·R:R1:3.5)、2.25 高空(强压·R:R1:3) |
| **80**（高确信） | 满足任一强确认：**明确背离/极端组合(C01/C02)/盘口预警**；或**多重强共振关键防守位**；或**顺势反弹空挂强压+高R:R** | 5.28 利空看跌背离极端组合、5.12 看跌背离4H、1.13 CVD看涨背离预警、4.20 周线W底共振·接飞刀低多、3.30 关键多头防守极限区回调多、2.4 CME缺口+区间下轨反弹需求(左侧)、3.22/3.13 顺势反弹空R:R1:3 |
| **85**（罕见·极高确信反转） | 明确背离 + 强压顺势反弹空 + 右侧确认，确信度极高时 | 5.18 晚反弹空 |

## 4. 与现有评分体系的接口（无需新数据源）
- **信号强度** ← `scoring/orderflow_methodology.md` 的盘口解读：极端候选(C01/C02·真极端70)＝最强；看跌/看涨背离（含小幅/4H）＝中强；"中性/中性偏多/中性偏空/散户没犯错"＝弱（→胜率落 70 baseline）。
- **结构位质量** ← `scoring/chart_methodology.md` 的盘面：多周期共振关键位/关键防守极限区/周线日线共振支撑阻力＝高；普通通道边缘＝中；中部无边缘＝（位置不优→挂价问题，非胜率，但若全程无高质量边缘则压低确信）。
- **盈亏比/事件窗口** ← Maker 计划字段与 FedWatch（数据公布前不确定→压低或观望）。

## 5. 硬约束（防漂移·防臆造）
1. **档位带 = 70–85**；自估落 <70 即**不开单**（写观望、不写"开一笔 65 的单"）。
2. **禁为了过门槛而臆造高胜率档**：信号/结构达不到 75/80 的确认，就如实给 70；70 都达不到（纯中性无边缘/事件不确定）就观望。准确性优先（[[stability-contract]]）。
3. **禁单变量定档**：胜率由"信号强度 + 结构质量"综合，单有一项不足不必然降档、单有一项强也需另一项不拖后腿（[[judgment-synthesis-not-extreme]]）。
4. **75/80 边界含主观成分**：rubric 抓主因，临界由综合权衡定，不过度公式化。
5. 胜率是**前瞻确信度**，出稿写进 Maker 计划"胜率X%"字段；**不与执行概率/已执行%/盈亏比混淆**。
