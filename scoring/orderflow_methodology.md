## 一、四个变量的本质（toggle 原文）

1. **CVD（主动买卖）**：市场用真金白银投票的方向。**看方向更看斜率——斜率代表力度。**
2. **价格**：结果，不是原因。**速度很重要：缓慢=虚弱/被引导；急速放量=真实意图。**
3. **持仓量OI（持仓变化）**：场内有没有"真实的人"在加仓。**OI增=加燃料，OI减=撤燃料。**
4. **资金费率**：散户情绪温度计，**反指**。正=多数做多，负=多数做空。**越接近极端，反转概率越大。**

### 🟥 读取铁律：价格锚点法（凌驾四维一切读数）
> **四维状态（CVD/价/OI/费率）必须用「1H 价格的摆动高/低点」为唯一锚点读取，四维共享同一时间锚。**
> - **第一步**：先定主导的 1H 价格 pivot（下跌腿=最近 1H 摆动高点 / 上涨腿=最近 1H 摆动低点）= 唯一锚点；
>   - 🟥🟥 **腿选择=确定性程序·趋势线破位判定法（凌驾"找最近转折"直觉）**：判断"在哪条腿"靠**主导趋势线是否被结构性破位**，不靠"最近一个转折"。①价格仍在趋势侧（下行线之下/上行线之上）=趋势未破→锚仍=启动该腿的摆动高(下跌)/低(上涨)，**腿内 counter-trend 小反弹/小回撤不重置锚点**（噪声非新腿）；②仅当趋势线被决定性突破（收盘明确越过+结构翻转 HH/HL 或 LH/LL）才重锚新腿。一句话：**选 pivot 看「趋势线是否被破」，非「最近有没有回弹」**。把未破主导趋势线的小反抽误当新腿，以及用指标自身极值替代价格 pivot，都是禁止的错锚模式。
> - **第二步**：价格方向 = pivot→现价斜率；
> - **第三步**：CVD/OI/资金费率都在「同一段」(price pivot→现值) 内读净变化斜率（上升/横盘/下降），资金费率再叠正/负；
> - **🟥 绝不让各维各取自己的局部极值**（旧 footprint_agent「三维各自独立取自己的阶段性高低点」已废）；指标末端 2-3 根微动是噪声、只看从价格 pivot 起的净变化。
>
> **为什么**：CVD/OI/费率存在的唯一意义＝判断「这一段价格运动是否被确认/背离」，确认与背离都是**相对价格**的概念——错锚（拿指标自身极值代替价格 pivot）会系统性高估方向力度、把噪声当趋势。
> **错锚模式 A：指标各取局部极值。** 这会把同一价格腿里的噪声误读为独立趋势，并改变组合编号与方向强度。正确做法是先锁 1H 价格 pivot，再从相同时间点读取 CVD/OI/费率净变化。
> **错锚模式 B：腿内反抽被误判为新腿。** 只要主导趋势线尚未结构性破位，反抽不重置 pivot；只有决定性突破并形成对应 HH/HL 或 LH/LL，才允许重锚。

## 二、核心判断心法（toggle 原文 · 灵魂）

1. 一切信号都是找"**散户在哪一边犯错**"。**散户不犯错=没机会=中性。**
2. 利多/利空是"**综合**"出来的，绝非单一变量决定。**先用主体趋势证据（CVD+价格+OI）定方向，再用资金费率/爆仓/现货这些"风险与印证因素"调整强度。**
3. **单变量（尤其资金费率）不能一票翻方向。接近极端=风险累积≠方向反转，必须等其他变量印证背离才动手。**
4. **燃料论**：上涨的燃料是被套空头，下跌的燃料是被套多头。**燃料烧尽=趋势到头。**
5. **诱导论**：价格缓慢朝一方向 + 情绪一边倒 + 持仓不配合（不进反退）= 诱（散户那边）。诱空=巨大看涨背离，诱多=巨大看跌背离。
6. **投入产出比**：CVD斜率 > 价格斜率 = 买力没兑现 = 隐性派发；反之隐性吸筹。
7. **流动性收割**：价格会寻找止损与强平密集区。清算地图只表达潜在通道与辅助印证，**只能调整概率和强度，不得单独断言收割完成、翻向，或替代用户手绘成交量分布区域。**

### 🟥 背离合成引擎（看涨/看跌信号如何从四维合成 · 核心本质 · 元规则）

> 背离方向用**杠杆陷阱 + 投入产出比 + 现货/杠杆分离**综合读取；不得把 CVD 与价格的单一表面关系直接当结论。
> 🟥 **与元规则 A 自洽（不矛盾）**：本引擎在「① 主体（价格 + CVD投入产出比 + OI）先定方向 → ② 资金费率/燃料调强度并识别被套的一方」框架内运作；**资金费率仍不单独一票翻向**——它识别谁被套，不凭空造方向。

**A. 背离＝杠杆陷阱（读"被套的那一方"，不是 CVD 对价格）。** 本质＝**某一方在加杠杆/投入、进入一个价格正在反向走（或不奖励）的行情 → 该方被套 → 被套方＝反向行情的燃料**（燃料论：上涨燃料=被套空头，下跌燃料=被套多头）。
- **看跌背离**＝多头在投入（CVD↑ 和/或 资金费率↑且正 和/或 OI↑多头）但价格**不涨反跌/横盘** → 多头买力没兑现/多头被套 → **看跌**（下跌燃料＝被套多头·已装填）。
- **看涨背离**＝空头在投入（CVD↓ 和/或 资金费率↓且负 和/或 OI↑空头）但价格**不跌反涨/横盘** → 空头被套 → **看涨**。

**B. 资金费率双轨升级（斜率读"谁在加燃料"，符号读"谁拥挤/付钱"——斜率此前漏读）。**
- 符号：正＝多头付钱/拥挤；负＝空头付钱/拥挤。
- **斜率：上升＝多头正在加杠杆（燃料流入多头侧）；下降＝多头去杠杆。** 加燃料的一方若价格与其相反＝正在制造被套盘＝反向背离燃料在装填。
- ∴ **费率「上升且为正」＋价格下降 ＝ 多头加杠杆防守未果 ＝ 被套多头燃料累积 ＝ 看跌**。镜像规则：费率「下降且为负」＋价格上升 ＝ 空头加杠杆被套 ＝ 看涨。

**C. 投入产出比方向锁死（此前读反过·务必照此·比的是斜率）。**
- **CVD斜率 > 价格斜率 ＝ 买力没兑现 ＝ 隐性派发 ＝ 看跌。** 含 **CVD横盘(0) + 价格下降(负)**（0 > 负）＝买力相对没兑现＝**看跌**，不得机械改读为“买盘吸收=看涨”。
- CVD斜率 < 价格斜率 ＝ 隐性吸筹 ＝ 看涨。包含 CVD横盘(0) + 价格上升(正) 的抽象镜像情形。

**D. 现货/杠杆分离。** CVD（perp taker）横盘/下降但价格下降 ＝ 主动盘没主导、**价格靠现货抛压压下来**＝真实供给（偏空背景）；叠加费率上升为正（杠杆多头加仓被套）＝看跌背离（现货真供给 ＋ 被套多头燃料）。CVD横盘 ≠ "买盘在托/卖压衰竭"。

**E. 背离（燃料已装填）评分 > 单边趋势（燃料已烧）。**
- **看跌背离（如 横盘/下降/下降/正）**：被套燃料尚未释放，可能仍有下跌续航；当前 production 具体 0–60 分由本轮背离质量、足迹确认、反证与失效风险落值。70 仅保留给未来原生结构化真极端证明能力，当前不可用。
- **单边空头趋势（如 下降/下降/横盘/正）**：主动卖已体现在价格里、燃料正在释放，剩余 edge 需要按本轮证据独立评估，不能套用历史固定分。
- ⚠️ 反直觉但锁死：**CVD横盘+价跌+费率升正的未释放背离燃料，可能比 CVD下降+价跌的已释放单边更具可操作性**；**禁把“CVD未放大”机械读成“卖压衰竭/relief/看涨”。**

**F. 效果背离以「CVD 是否创新高/低 vs 价格是否同步创新高/低」为准 —— 价格反抽 ≠ 价格创新高。**
- 🟥 **看跌背离的判据＝CVD 创新高（买力大量投入）但价格未同步创新高（买力未兑现于价格·被卖方吸收）**；镜像看涨背离＝CVD 创新低（卖力大量投入）但价格未同步创新低（卖力未兑现·被买方承接）。
- 🟥 **「价格上升/反抽/升破小压」≠「价格创新高」**：超跌后的 relief 反抽里，价格往往只是从低点弹起、或升破某个 minor/破位下沿压力，但**仍远低于前波段高点**＝**未创新高**。此时若 CVD 已创新高（甚至回到/超过前高时的水平）而价格远不及前高 ＝ **买盘效率背离 ＝ 看跌背离**（不是"价格上升＝确认型上涨"）。
- 🟥 **禁止模式**：把反抽或升破次级压力直接等同于创新高。**判背离一律做效果对照：CVD 的新高/新低，价格有没有同步越过同一 pivot 对应的前高/前低；未同步才构成效果背离，再由 OI、费率与足迹确认强度。**
- 操作落点：CVD 新高 + 价格未创新高（看跌背离）＝顺 HTF 空头的**反弹空**信号增强（背离＋顺势），挂价于反抽冲到的高质量结构压力边缘。

**G. OI 在反抽中下降的双重含义 —— 空头回补 squeeze（偏多）vs 获利空头止盈出局＋现货抛压（偏空/中性）。**
- 价格反抽 + OI 下降，**不可机械读成"空头回补 squeeze＝逼空撑涨＝偏多"**。两种相反含义：
  - (a) **空头回补 squeeze（偏多）**：空头被逼，被动买回平仓推价 → 通常伴随**价格突破/创新高**（逼空动能把价顶上去）。
  - (b) **短期获利空头止盈出局 ＋ 现货抛压持续（偏空/中性）**：前期大跌中的盈利空单主动止盈平仓（机械减少 OI），但**无新多承接、底层现货卖压未消** → 通常伴随**价格滞涨、未创新高**（反抽靠获利了结驱动、缺真实买盘续航）。
- 🟥 **区分钥匙＝价格有没有创新高**：OI↓ + 价格创新高/突破 → 偏 squeeze(a)；OI↓ + 价格未创新高/滞涨 → 偏获利了结+现货抛压(b)＝叠加 CVD 创新高即**看跌背离**。**OI 不增＝没有新多真实承接＝反抽缺续航燃料**（与 F 的"价格未创新高"互为印证）。
- 因此必须先检查价格是否真正突破同一 pivot 的结构高点，再结合 CVD 效果、OI 减仓性质、现货侧与足迹证据裁决；不能只看 `OI↓` 就命名 squeeze。

## 三、信号分级 + 评分规则

**评分规则（当前 production 统一落 0–60；极端只作候选分类）：**
- **极端四维 = "极端候选"，不是机械高分**：CVD上升 价格下降 持仓上升或横盘 且费率正（看跌背离候选）；CVD下降 价格上升 持仓上升或横盘 且费率负（看涨背离候选）。
  - 当前无论是否真极端都只能在 0–60 内由本轮结构化证据与 rationale 确定性落值，不由个人感觉或分档习惯决定。
  - 同一极端四维会因背离质量、足迹确认、反证与失效风险不同而取不同的 0–60 分；骨架只给候选，不直接给分。
- **硬约束：当前所有 C01–C81 一律 ≤60，61–69 一律非法，70 当前不可用。70 只有在未来另行实现并批准原生结构化真极端证明验证器后才可能启用，配置变更本身不构成启用授权。**
- **其余组合由本轮证据在 0–60 内确定性落值；禁止默认 0、手工凑分或套用历史粗档。**

**评分颗粒度：**普通与极端候选当前均在 0–60 内按证据使用任意整数。61–69 是非法区间；70 是未启用的未来保留值，不得成为绕过当前上限的跳档。

**信号词（toggle 信号分级，备注里自由表述）：** 利多 / 中性偏多 / 中性 / 中性偏空 / 利空。

## 四、综合权衡流程 + 元规则（含两次纠正 · 铁律）

**流程：① 先用主体三件套（CVD+价格+OI）定方向 → ② 再用资金费率/爆仓/现货/多周期/斜率调强度与分数。**

**元规则（违反即飘移）：**
- **A. 单变量不翻向**：任何单变量（尤其资金费率）不能一票翻方向；接近极端=风险累积≠反转。
- **B. 事实 > 推测**：CVD上升=主动买是**客观事实**=方向基础；"隐性派发/诱多/诱空"是**推测**。
- **C. 散户犯错要硬证据、不可预判**：费率不极端、无明确"打钱"押注、无明确诱导结构=散户没犯错=中性。
- **D. 斜率背离缺印证只降级不翻转**：散户没犯错时，斜率背离只把方向"利多→中性"，**绝不翻成偏空**。要转偏空需硬印证（费率转正且接近极端+价格滞涨转跌+OI多头不进反退）。
- **E. 不走极端、不预测顶底。**

## 六、当前证据校准程序

1. 先以同一 1H 价格 pivot 读取 CVD、价格、OI、费率，并确定 C01–C81 编号。
2. 再做效果背离、投入产出比、OI 双重语义、资金费率边界与 Exocharts 足迹交叉验证。
3. 先写主判，再写最强反证、失效条件和残余不确定性；最后才落绝对分数。
4. 非极端在 0–60 内按当前证据自由细分；平衡、燃料不足、冲突或证据不完整应显著降分。
5. 当前所有组合最高 60，61–69 非法，70 不可用。未来若另行实现并批准原生结构化真极端证明验证器，C19/C22/C56/C59 仍须同时满足同一 1H 价格 pivot、极端组合、效果背离、OI/价格语义、资金费率仅作修正且未单变量翻向、Exocharts 明确 `confirm`、最强反证与失效路径闭环，才可能使用 70；配置变更不能单独开启。
6. 历史日期、价格、方向、分数、手工存储选项与旧报告文字均不得进入运行期推理。

## 八、Footprint 足迹信号（Exocharts 微观订单流 · 综合权衡的印证因子）

> **定位（宪法级）**：🟥 **盘口四变量（CVD/价格/OI/资金费率）的解读核心 = Coinglass 同一 BTC 1H pivot 的四面板。Exocharts 不是盘口主源，只是「确认／削弱／反驳 + 更细颗粒度的数据参照」**。Exocharts 的独有价值是逐价位主动买卖、Delta、失衡、POC、CVD 与 Volume 足迹；四维主判断来自 Coinglass，微观确认来自 Exocharts。两源冲突必须显式写反证并复核，Exocharts 不单方覆盖或翻转 Coinglass 主判断。
>
> **采集配置（缺一即不可作为本轮 Exocharts 证据）**：先选 `Bybit BTCUSD`，再精确确认 `D`、`Tick 120`、`Bid-Ask Profile`、`Imbalance`、`Candle None`、`FPBS`、`vWap`。
>
> 🟥 **两条铁律（违反即飘移）**：
> 1. **足迹信号绝不单独翻向、绝不单独制造极端**（元规则 A/B）。方向永远由 CVD+价格+OI 先定；Exocharts 只能确认、削弱或反驳。当前无论 `confirm` / `weaken` / `contradict`，盘口均不得超过 60；`confirm` 仅在未来原生结构化真极端证明能力启用后才可能成为 70 的必要条件之一。
> 2. **缺足迹数据 = 降级不阻塞、绝不臆造**（稳定性宪法·禁幻觉）。用户截图常无 footprint 档位；无则标 `footprint_signals: unavailable`，按现有四维综合正常出分，**严禁编造失衡/吸收/POC**。

### 三类足迹信号（各绑定既有心法编号）

**1. 吸收 Absorption**（绑 心法 4 燃料论 + 心法 5 诱导论 + 心法 6 投入产出比微观版）
- 定义：某价位/区间出现**大额主动成交（大 delta）但价格停滞或反向** → 被动挂单方在吸收主动单。
- 读取：该价位主动买/卖量显著高于邻近 K，但价格位移≈0 或反向。
- 心法含义：大量主动**买**被吸收 = **隐性派发**印证（卖方挂单接货）；大量主动**卖**被吸收 = **隐性吸筹**印证（买方挂单接货）。
- 作用：**只印证已成立的背离方向** —— 当前只能在 0–60 域内调整候选强度；未来原生结构化真极端证明能力启用后，才可能成为 70 的必要确认之一。不得据此凭空生成背离方向（心法 B：吸收是推测的微观证据，方向仍须主体三件套先定）。

**2. 失衡 Imbalance / 堆叠失衡 Stacked Imbalance**（绑 心法 B 事实>推测 + 心法 2 价格速度）
- 定义：footprint 对角线买量:卖量超阈值（惯例 **≥3:1**）= 单点失衡；连续 **≥3 档**同向 = 堆叠失衡。
- 读取：买失衡堆叠 = 强势主动买；卖失衡堆叠 = 强势主动卖。
- 心法含义：堆叠失衡 = CVD 方向"**真实意图**"的微观确认（急速放量=真实；零散无堆叠=缓慢/被引导）。
- 作用：**印证 CVD 方向的真实度** —— 堆叠失衡与 CVD 同向 → 该方向力度可+一档强度；CVD 有方向但 footprint 无堆叠失衡（零散）→ 判"被引导"，该方向降级。**仍不翻向**。

**3. POC / 价值区迁移 Point of Control**（绑 心法 7 流动性收割 + 结构）
- 定义：当前段成交量最大价位 = POC；约 70% 成交量区间 = 价值区。
- 读取：POC 相对前一段**上移/下移/持平**；现价相对 POC 的**偏离程度**。
- 心法含义：价格远离 POC = 回归概率高（流动性磁吸）；POC 单向迁移 = 价值中枢迁移（背景方向印证）。
- 作用：**背景/结构印证 + 追单速度判断** —— 现价远离 POC 且无堆叠失衡支撑 → 易回 POC，对追单降级；POC 迁移与主体方向一致 → 背景印证。**不构成当前 0–60 评分之外的加分，也不构成未来保留 70 的独立证明**，仅折进 rationale 与强度微调。
- 🔗 **跨源边界**：本节 POC 是 Exocharts 日线足迹中的微观成交中心，只能辅助盘口强弱与追单速度，不能替代 TradingView 的用户手绘成交量分布、不能生成各周期猎杀概率落点，也不能作为 Maker 挂价来源。流动性猎杀位置/概率只认 TradingView 可读的用户手绘区域；该 profile 不足时，Coinglass 清算热力图保持 `neutral`，不得用 Exocharts POC 或清算带补齐。

### 接入综合权衡的位次（不改流程、不改分上限）

在第四节「① 主体三件套定方向 → ② 风险/印证因素调强度」的**②阶段**，足迹信号与爆仓/现货/多周期**并列**作印证因子：
- 与方向一致 → 在当前 0–60 连续整数域内按证据上调强度；对极端候选也只能提升其质量判断，当前不得直接取 70，61–69 同样禁止。
- 与方向矛盾 / 无堆叠失衡 / 现价远离 POC → **降级**（仅降不翻，元规则 D）。
- 最终分仍受硬约束：**当前一律 ≤60；61–69 一律非法；70 为未来原生结构化证明保留值且不可由配置启用**（第三节不变）。
- 足迹证据一律写入 `rationale`，并绑定本轮 Exocharts 证据路径，供结构化合同逐条复核。
