## 一、四个变量的本质（toggle 原文）

1. **CVD（主动买卖）**：市场用真金白银投票的方向。**看方向更看斜率——斜率代表力度。**
2. **价格**：结果，不是原因。**速度很重要：缓慢=虚弱/被引导；急速放量=真实意图。**
3. **持仓量OI（持仓变化）**：场内有没有"真实的人"在加仓。**OI增=加燃料，OI减=撤燃料。**
4. **资金费率**：散户情绪温度计，**反指**。正=多数做多，负=多数做空。**越接近极端，反转概率越大。**

### 🟥 读取铁律：价格锚点法（2026-06-17 用户纠正后锁死 · 凌驾四维一切读数）
> **四维状态（CVD/价/OI/费率）必须用「1H 价格的摆动高/低点」为唯一锚点读取，四维共享同一时间锚。**
> - **第一步**：先定主导的 1H 价格 pivot（下跌腿=最近 1H 摆动高点 / 上涨腿=最近 1H 摆动低点）= 唯一锚点；
>   - 🟥🟥 **腿选择=确定性程序·趋势线破位判定法（2026-06-19 二次锚错腿后补，凌驾"找最近转折"直觉）**：判断"在哪条腿"靠**主导趋势线是否被结构性破位**，不靠"最近一个转折"。①价格仍在趋势侧（下行线之下/上行线之上）=趋势未破→锚仍=启动该腿的摆动高(下跌)/低(上涨)，**腿内 counter-trend 小反弹/小回撤不重置锚点**（噪声非新腿）；②仅当趋势线被决定性突破（收盘明确越过+结构翻转 HH/HL 或 LH/LL）才重锚新腿。一句话：**选 pivot 看「趋势线是否被破」，非「最近有没有回弹」**。把"未破下行线的小反抽"误当"新上涨腿"读「四维上升」＝6/19 锚错腿（与 6/17「用指标自身极值」并列两类错锚）。
> - **第二步**：价格方向 = pivot→现价斜率；
> - **第三步**：CVD/OI/资金费率都在「同一段」(price pivot→现值) 内读净变化斜率（上升/横盘/下降），资金费率再叠正/负；
> - **🟥 绝不让各维各取自己的局部极值**（旧 footprint_agent「三维各自独立取自己的阶段性高低点」已废）；指标末端 2-3 根微动是噪声、只看从价格 pivot 起的净变化。
>
> **为什么**：CVD/OI/费率存在的唯一意义＝判断「这一段价格运动是否被确认/背离」，确认与背离都是**相对价格**的概念——错锚（拿指标自身极值代替价格 pivot）会系统性高估方向力度、把噪声当趋势。
> **实证教训（2026-06-17 晚）**：价格自 6/16 1H 摆动高 66,950 下挫至 64,800（价格下降）。错锚＝拿 CVD 自身局部高 -12K 比现 -14.6K → 误读「CVD 下降」→ C79（卖压坐实·偏空）。正锚＝锚定 6/16 价格高点，CVD 自 -13K 到 -14.6K 近水平 → **CVD 横盘**（卖压未放大→隐性派发=小幅看跌背离·看跌，**非"吸收=看涨"**·见 §二）→ **C52（横盘/下降/下降/正）**＝中性偏空·弱（下挫系缺买盘+现货真供给而非新空猛砸）。两者方向力度与组合编号完全不同。详见 `agents/footprint_agent.md` §统一读取法。
> **实证教训②（2026-06-19 早·二次锚错腿·方向相反地复犯）**：价自 6/16 摆动高 ~66,950 沿下行趋势线下挫至现 ~62,950（下跌腿·未破下行线），末段几小时小反抽 62,000→63,020。❌ 错锚＝把小反抽当新上涨腿 → 读「CVD上升/价格上升/OI横盘微降/费率正」。✅ 正锚（趋势线破位判定法：小反抽未破下行线→腿仍是下跌腿、锚仍=66,950）→「CVD横盘/价格下降/持仓横盘/费率上升为正」＝小幅看跌背离·55（同 6/17 档）。两类锚错（6/17 指标自身极值、6/19 锚错腿）均由本节「腿选择确定性程序」+「四维共享价格锚」根治。

## 二、核心判断心法（toggle 原文 · 灵魂）

1. 一切信号都是找"**散户在哪一边犯错**"。**散户不犯错=没机会=中性。**
2. 利多/利空是"**综合**"出来的，绝非单一变量决定。**先用主体趋势证据（CVD+价格+OI）定方向，再用资金费率/爆仓/现货这些"风险与印证因素"调整强度。**
3. **单变量（尤其资金费率）不能一票翻方向。接近极端=风险累积≠方向反转，必须等其他变量印证背离才动手。**
4. **燃料论**：上涨的燃料是被套空头，下跌的燃料是被套多头。**燃料烧尽=趋势到头。**
5. **诱导论**：价格缓慢朝一方向 + 情绪一边倒 + 持仓不配合（不进反退）= 诱（散户那边）。诱空=巨大看涨背离，诱多=巨大看跌背离。
6. **投入产出比**：CVD斜率 > 价格斜率 = 买力没兑现 = 隐性派发；反之隐性吸筹。
7. **流动性收割**：价格是去扫止损的。**爆仓数据看收割完成度，一侧割完→转向另一侧。**

### 🟥 背离合成引擎（2026-06-17 用户两次纠正后锁死 · 看涨/看跌信号如何从四维合成 · 核心本质 · 元规则）

> 背离的方向**不用教科书「CVD vs 价格」读**，而用**杠杆陷阱 + 投入产出比 + 现货/杠杆分离**读。2026-06-17 把 `横盘/下降/下降/正` 误判成"吸收=轻微看涨/relief"（真值＝小幅看跌背离），即违反本引擎。
> 🟥 **与元规则A自洽（不矛盾）**：本引擎在「① 主体（价格 + CVD投入产出比 + OI）先定方向 → ② 资金费率/燃料调强度并识别"被套的那一方"」框架内运作；**资金费率仍不单独一票翻向**——它识别谁被套（燃料方向），不凭空造方向。今晚的看跌方向来自 价格下降 + 投入产出比（CVD横盘>价跌=隐性派发）这两个主体证据，费率上升只是印证"被套多头燃料在装填"、强化续航。

**A. 背离＝杠杆陷阱（读"被套的那一方"，不是 CVD 对价格）。** 本质＝**某一方在加杠杆/投入、进入一个价格正在反向走（或不奖励）的行情 → 该方被套 → 被套方＝反向行情的燃料**（燃料论：上涨燃料=被套空头，下跌燃料=被套多头）。
- **看跌背离**＝多头在投入（CVD↑ 和/或 资金费率↑且正 和/或 OI↑多头）但价格**不涨反跌/横盘** → 多头买力没兑现/多头被套 → **看跌**（下跌燃料＝被套多头·已装填）。
- **看涨背离**＝空头在投入（CVD↓ 和/或 资金费率↓且负 和/或 OI↑空头）但价格**不跌反涨/横盘** → 空头被套 → **看涨**。

**B. 资金费率双轨升级（斜率读"谁在加燃料"，符号读"谁拥挤/付钱"——斜率此前漏读）。**
- 符号：正＝多头付钱/拥挤；负＝空头付钱/拥挤。
- **斜率：上升＝多头正在加杠杆（燃料流入多头侧）；下降＝多头去杠杆。** 加燃料的一方若价格与其相反＝正在制造被套盘＝反向背离燃料在装填。
- ∴ **费率「上升且为正」＋价格下降 ＝ 多头加杠杆防守未果 ＝ 被套多头燃料累积 ＝ 看跌**（今晚锚）。镜像：费率「下降且为负」＋价格上升 ＝ 空头加杠杆被套 ＝ 看涨。

**C. 投入产出比方向锁死（此前读反过·务必照此·比的是斜率）。**
- **CVD斜率 > 价格斜率 ＝ 买力没兑现 ＝ 隐性派发 ＝ 看跌。** 含 **CVD横盘(0) + 价格下降(负)**（0 > 负）＝买力相对没兑现＝**看跌**（≠"买盘吸收=看涨"，此为 6/17 误读根）。
- CVD斜率 < 价格斜率 ＝ 隐性吸筹 ＝ 看涨。含 CVD横盘(0) + 价格上升(正)＝看涨（6/10 样本）。

**D. 现货/杠杆分离。** CVD（perp taker）横盘/下降但价格下降 ＝ 主动盘没主导、**价格靠现货抛压压下来**＝真实供给（偏空背景）；叠加费率上升为正（杠杆多头加仓被套）＝看跌背离（现货真供给 ＋ 被套多头燃料）。CVD横盘 ≠ "买盘在托/卖压衰竭"。

**E. 背离（燃料已装填）评分 > 单边趋势（燃料已烧）。**
- **看跌背离（如 横盘/下降/下降/正 ＝ 55；上升/下降/上升/正 ＝ 60-70 极端）**：被套燃料**尚未释放**＝下跌仍有续航＝高 edge。
- **单边空头趋势（如 下降/下降/横盘/正 ＝ 40）**：主动卖已在 price 里、燃料正在烧＝剩余 edge 低。
- ⚠️ 反直觉但锁死：**CVD横盘+价跌+费率升正（看跌背离·55）比 CVD下降+价跌（单边·40）更偏空-可操作**；**禁把"CVD未放大"读成"卖压衰竭/relief/看涨"。**

**F. 效果背离以「CVD 是否创新高/低 vs 价格是否同步创新高/低」为准 —— 价格反抽 ≠ 价格创新高（2026-06-21 用户订正·关键盘口底层逻辑·避免重复错误）。**
- 🟥 **看跌背离的判据＝CVD 创新高（买力大量投入）但价格未同步创新高（买力未兑现于价格·被卖方吸收）**；镜像看涨背离＝CVD 创新低（卖力大量投入）但价格未同步创新低（卖力未兑现·被买方承接）。
- 🟥 **「价格上升/反抽/升破小压」≠「价格创新高」**：超跌后的 relief 反抽里，价格往往只是从低点弹起、或升破某个 minor/破位下沿压力，但**仍远低于前波段高点**＝**未创新高**。此时若 CVD 已创新高（甚至回到/超过前高时的水平）而价格远不及前高 ＝ **买盘效率背离 ＝ 看跌背离**（不是"价格上升＝确认型上涨"）。
- 🟥 **错误模式（2026-06-21 早盘亲历·必须根除）**：把"价格反抽 +3%、升破 63,900-64,150 破位下沿"误当成"价格上升＝确认型上涨/中性 relief"，忽略了"CVD 已创窗口新高 16.65K、而价格 64,221 远低于 6/15-16 前高 66,800＝未创新高"＝实为看跌背离。**判背离一律做「效果对照」：CVD 的新高/新低，价格有没有同步跟上？没跟上＝背离，方向＝买力/卖力被吸收的反方向。**
- 操作落点：CVD 新高 + 价格未创新高（看跌背离）＝顺 HTF 空头的**反弹空**信号增强（背离＋顺势），挂价于反抽冲到的高质量结构压力边缘。

**G. OI 在反抽中下降的双重含义 —— 空头回补 squeeze（偏多）vs 获利空头止盈出局＋现货抛压（偏空/中性）（2026-06-21 订正）。**
- 价格反抽 + OI 下降，**不可机械读成"空头回补 squeeze＝逼空撑涨＝偏多"**。两种相反含义：
  - (a) **空头回补 squeeze（偏多）**：空头被逼，被动买回平仓推价 → 通常伴随**价格突破/创新高**（逼空动能把价顶上去）。
  - (b) **短期获利空头止盈出局 ＋ 现货抛压持续（偏空/中性）**：前期大跌中的盈利空单主动止盈平仓（机械减少 OI），但**无新多承接、底层现货卖压未消** → 通常伴随**价格滞涨、未创新高**（反抽靠获利了结驱动、缺真实买盘续航）。
- 🟥 **区分钥匙＝价格有没有创新高**：OI↓ + 价格创新高/突破 → 偏 squeeze(a)；OI↓ + 价格未创新高/滞涨 → 偏获利了结+现货抛压(b)＝叠加 CVD 创新高即**看跌背离**。**OI 不增＝没有新多真实承接＝反抽缺续航燃料**（与 F 的"价格未创新高"互为印证）。
- 实证（2026-06-21 早）：CVD 创新高 / 价格未创新高 / OI 54K→50.8K / 费率正 ＝ 获利空头止盈+现货抛压(b)＋看跌背离 ＝ 中性偏空 55（非"空头回补撑涨的中性 relief"）。

**真值锚（用户 Notion 盘口库 52 样本 · 不可推翻）：** 6/17 晚 横盘/下降/下降/正 ＝ 中性偏空·小幅看跌背离·**55**；6/17 早 上升/下降/下降/正 ＝ 中性偏空·小幅看跌背离·55；6/10 横盘/上升/下降/接近0 ＝ 小幅看涨背离·55；6/2 晚 下降/下降/横盘/正 ＝ 单边空头·40；5/18 晚 上升/下降/上升/正 ＝ 看跌背离极端·70；**6/21 早 上升(创新高)/上升(未创新高)/下降/正 ＝ 中性偏空·看跌背离·获利了结型·55（CVD 创新高但价格未创新高＝买力被吸收；OI 降＝获利空头止盈+现货抛压·非 squeeze）**。

## 四、综合权衡流程 + 元规则（含两次纠正 · 铁律）

**流程：① 先用主体三件套（CVD+价格+OI）定方向 → ② 再用资金费率/爆仓/现货/多周期/斜率调强度与分数。**

**元规则（违反即飘移）：**
- **A. 单变量不翻向**：任何单变量（尤其资金费率）不能一票翻方向；接近极端=风险累积≠反转。
- **B. 事实 > 推测**：CVD上升=主动买是**客观事实**=方向基础；"隐性派发/诱多/诱空"是**推测**。
- **C. 散户犯错要硬证据、不可预判**：费率不极端、无明确"打钱"押注、无明确诱导结构=散户没犯错=中性。
- **D. 斜率背离缺印证只降级不翻转**：散户没犯错时，斜率背离只把方向"利多→中性"，**绝不翻成偏空**。要转偏空需硬印证（费率转正且接近极端+价格滞涨转跌+OI多头不进反退）。
- **E. 不走极端、不预测顶底。**

## 八、Footprint 足迹信号（exocharts 微观订单流 · 综合权衡的「印证因子」· 2026-06-14 迭代）

> **定位（2026-06-14 用户校准·宪法级）**：🟥 **盘口四变量（CVD/价/持仓/费率）的解读核心 = coinglass 一张截图（四变量同屏）。exocharts 不是盘口主源，只是「印证 + 更细颗粒度的数据参照」**，确保 coinglass 判断准确。exocharts 区别于 coinglass 的独有价值 = 逐价位订单流足迹（每价位主动买/卖 delta、对角线失衡、POC）= 上面说的"更细颗粒度"。四维（读自 coinglass）是**宏观方向**，足迹信号（来自 exocharts）是**微观印证**。足迹信号是「**心法因素**」（与爆仓/现货/多周期同级），**写进「备注」/rationale，不新增库字段、不新增极端组合**。exocharts 与 coinglass 冲突时**以 coinglass 为准复核**，exocharts 不单方覆盖。
>
> 🟥 **两条铁律（违反即飘移）**：
> 1. **足迹信号绝不单独翻向、绝不单独制造极端**（元规则 A/B）。它只在**主体三件套已定出的方向**上调强度、调 60↔70 候选质量，或对追单降级。方向永远由 CVD+价格+OI 先定。
> 2. **缺足迹数据 = 降级不阻塞、绝不臆造**（稳定性宪法·禁幻觉）。用户截图常无 footprint 档位；无则标 `footprint_signals: unavailable`，按现有四维综合正常出分，**严禁编造失衡/吸收/POC**。

### 三类足迹信号（各绑定既有心法编号）

**1. 吸收 Absorption**（绑 心法 4 燃料论 + 心法 5 诱导论 + 心法 6 投入产出比微观版）
- 定义：某价位/区间出现**大额主动成交（大 delta）但价格停滞或反向** → 被动挂单方在吸收主动单。
- 读取：该价位主动买/卖量显著高于邻近 K，但价格位移≈0 或反向。
- 心法含义：大量主动**买**被吸收 = **隐性派发**印证（卖方挂单接货）；大量主动**卖**被吸收 = **隐性吸筹**印证（买方挂单接货）。
- 作用：**只印证已成立的背离方向** —— 把"接近极端 60"质量推向"真极端 70"，或把同向一致信号降级。不得据此凭空生成背离方向（心法 B：吸收是推测的微观证据，方向仍须主体三件套先定）。

**2. 失衡 Imbalance / 堆叠失衡 Stacked Imbalance**（绑 心法 B 事实>推测 + 心法 2 价格速度）
- 定义：footprint 对角线买量:卖量超阈值（惯例 **≥3:1**）= 单点失衡；连续 **≥3 档**同向 = 堆叠失衡。
- 读取：买失衡堆叠 = 强势主动买；卖失衡堆叠 = 强势主动卖。
- 心法含义：堆叠失衡 = CVD 方向"**真实意图**"的微观确认（急速放量=真实；零散无堆叠=缓慢/被引导）。
- 作用：**印证 CVD 方向的真实度** —— 堆叠失衡与 CVD 同向 → 该方向力度可+一档强度；CVD 有方向但 footprint 无堆叠失衡（零散）→ 判"被引导"，该方向降级。**仍不翻向**。

**3. POC / 价值区迁移 Point of Control**（绑 心法 7 流动性收割 + 结构）
- 定义：当前段成交量最大价位 = POC；约 70% 成交量区间 = 价值区。
- 读取：POC 相对前一段**上移/下移/持平**；现价相对 POC 的**偏离程度**。
- 心法含义：价格远离 POC = 回归概率高（流动性磁吸）；POC 单向迁移 = 价值中枢迁移（背景方向印证）。
- 作用：**背景/结构印证 + 追单速度判断** —— 现价远离 POC 且无堆叠失衡支撑 → 易回 POC，对追单降级；POC 迁移与主体方向一致 → 背景印证。**不计入 70 分极端**，仅折进 rationale 与强度微调。
- 🔗 **流动性猎杀概率**：POC/VAL/VAH 是判「各周期高/低点被猎杀概率」的**主判**工具，Coinglass 清算热力图作**辅助印证**——完整逻辑见 `scoring/chart_methodology.md §九`（流动性获取/猎杀底层逻辑·盘面权威）。

### 接入综合权衡的位次（不改流程、不改分上限）

在第四节「① 主体三件套定方向 → ② 风险/印证因素调强度」的**②阶段**，足迹信号与爆仓/现货/多周期**并列**作印证因子：
- 与方向一致 → 在既有分档内**+强度**（如 50→55、接近极端 60→70 候选质量提升）。
- 与方向矛盾 / 无堆叠失衡 / 现价远离 POC → **降级**（仅降不翻，元规则 D）。
- 最终分仍受硬约束：**只有极端候选能到 70；非极端一律 ≤60**（第三节不变）。
- 足迹证据一律写入「备注」/`rationale`，可被 Notion 真实库逐条复核。
