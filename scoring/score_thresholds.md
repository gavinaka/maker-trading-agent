# 分数阈值与行为映射

# 总评分结构
评分 schema 名义容量 = 盘口70 + 盘面30 = 100；当前 production 有效值域 = 盘口0–60 + 盘面0–30，总分最高90。盘口61–69非法，70为未来原生结构化证明保留值且当前不可用。

---

# 核心开仓门槛

## 门槛资格与计划可构造性（先判断、后执行）
- **门槛① 总评分 ≥ 65分**
- **门槛② 计划时置信度 ≥ 60%**；按 `scoring/winrate_methodology.md` 使用 0–100 连续整数真实估值，不锁固定档、不从开单结果或门槛倒推
- 机器语义：门槛②使用 `plan_time_conviction`，不是统计命中概率。样本不足期间必须保持 `calibrated_probability=false`；门槛规则保留，但不得对外宣称“60%=真实60%命中率”。
- 两门槛全部满足只得到 `threshold_eligible=true`；任一门槛不满足即 `threshold_eligible=false`，本轮观望、不挂单。
- `plan_constructible=true` 还必须同时满足：Maker thesis 与 Maker-only `cannot_do` 不冲突；存在本轮 TradingView 认证的高质量 `entry_zone`；2–5 档全部落在该区间且比例合计 100%；每个非空部分成交组合的 TP1 盈亏比与名义风险均通过。
- 只有 `threshold_eligible=true` 且 `plan_constructible=true`，`plan_state` 才能是 `qualified` 并生成完整 Maker 限价阶梯。门槛达标但没有认证区间、方向禁令冲突或风险数学不成立时，正确业务结果是带结构化原因的 `observe`，不是工程失败，也不得为满足模板伪造价格。

> 🟢 **入场价格触达概率 ≥ 50% = 软参考·非硬门槛**：它只描述当前价到认证区间的可达性，不是订单实际成交概率；不能把已构造完成的合格计划降格，也不能为提高可达性把挂价移出认证区间。
> production 的开仓前执行资格只决定是否真实下单；shadow 固定不读取个人/生活状态。两者均不得改变 `threshold_eligible`、`plan_constructible`、`plan_state`、方向、评分、价格或风险。上述资格与构造性都在既有 decision/risk 门内处理，不新增第五道门。

# 分数区间行为映射

## 0 - 49分
### 市场状态
- 结构混乱
- 无明显优势
- 风险收益比不足

### 执行动作
- 强制观望
- 禁止主观交易
- 禁止寻找理由开仓

## 50 - 64分
### 市场状态
- 存在部分结构
- 共振不足
- 不满足系统要求

### 执行动作
- 默认观望
- 允许持续观察
- 禁止提前入场

## 65 - 84分
### 市场状态
- 达到系统要求
- 存在较高共振
- 风险收益比合理

### 执行动作
- 在计划时置信度门槛也满足且 `plan_constructible=true` 时，**必须生成标准 Maker 计划**；production 是否真实挂单另由执行资格决定，shadow 固定只验证不执行。
- 方向由 Coinglass 同锚主判，Exocharts 只确认/削弱/反驳且不得翻向；**挂单区间只设在 TradingView 当次四周期结构或可读用户手绘区域明确认证的高质量边缘**，并用 2–5 档真实不同价格和合计 100% 比例执行。手绘 profile 不足时不得由清算图或 Exocharts POC 补位，但仍可使用当次可验证并显式给出上下界的结构区间。
- 必须完成全部风控检核（Gate2）
- `cannot_do` 必须在独立Maker thesis、反证、失效与三类情景全部完成后通过终局兼容校验（Gate3）；它是output-only终值，不得生成或翻转方向，也不得被任何observation、claim、反证、失效或情景引用
- production 的状态门禁只决定真实 `execution_action`，不参与 `plan_state`；shadow 禁止读取该门禁

> **「必开」只适用于 `threshold_eligible && plan_constructible` 的合格计划**，含义是必须生成完整 Maker 限价阶梯，而非市价立即成交。低入场价格触达概率或“距离较远”不能否决已有认证区间；但订单生命周期不可行、本轮不存在认证高质量区间等 constructibility 失败必须令 `plan_constructible=false` 并观望。不得用市价追单、单点代表价或一次性满仓取代区间。

## 85 - 90分（当前可达高分区；91–100为未来保留且当前不可达）
### 市场状态
- 极强共振
- 高质量结构
- 极端盘口背离

### 执行动作
- 优先级最高
- 可执行核心策略
- 必须严格按照系统执行

# 极端候选规则
以下为极端候选（看跌/看涨背离）。**极端=候选、不是跳到保留值的理由**——当前所有候选与非极端组合都必须按本轮证据在0–60内精细落值。70只有在未来另行实现并批准原生结构化真极端证明验证器后才可能启用。详见 `scoring/orderflow_methodology.md`。

> 本节只讨论盘口分。当前 production 合法值仅为0–60内任意整数；61–69非法，70不可用且不得通过配置单独启用。未来若原生结构化真极端证明验证器获批启用，70仍必须满足同一1H pivot、C19/C22/C56/C59极端组合、效果背离、OI/价格语义、资金费率仅作修正且未单变量翻向、Exocharts `confirm`、最强反证与失效路径闭环。

## 看跌背离
- CVD上升
- 价格下降
- 持仓上升或横盘
- 资金费率为正值

→ 看跌背离候选；必须完成综合确认、位置、反证与双门槛后才形成 Maker 空单计划。

## 看涨背离
- CVD下降
- 价格上升
- 持仓上升或横盘
- 资金费率为负值

→ 看涨背离候选；必须完成综合确认、位置、反证与双门槛后才形成 Maker 多单计划。

# 强制原则
评分系统高于感觉，高于预测，高于情绪。

---

# 禁止事项
禁止：
- 临时修改评分
- 情绪化提高评分
- 为了开仓强行解释结构
- 未达到65分强行交易
- 用入场价格触达概率 <50% 否决开仓（触达概率非硬门槛、不是实际成交概率，不决定是否开仓）
- 把盘口分填写为61–69，或在当前 production 把任何候选写成70
- **`threshold_eligible && plan_constructible` 已成立，却仅以入场价格触达概率低、距离远或 live 执行资格关闭为由降格候选计划**
- **本轮没有 TradingView 认证高质量区间时，为了满足双门槛而主观制造区间**
- **把 Maker 单挂在非高质量边缘的位置去追价**（必挂的是边缘单，不是追价单）
