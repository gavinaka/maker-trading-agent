# 出场模型（图谱第七节 + 二十节）

> 系统核心理念：**出场比入场更重要**。
> TP1 后的剩余仓位运行是关键（图谱二十节）。
> 与 `risk/floating_defense.md` 配合使用。

---

## 出场优先级（图谱二十节，2026.5 迭代后）

| 优先级 | 维度 |
|---|---|
| **第一** | 盈亏比（1.5R / 2.5R） |
| **第二** | 胜率（参考，非核心决策变量） |

> ⚠️ 此处「胜率非核心决策变量」仅指**离场/选单阶段**的优化优先级（盈亏比 > 胜率）。与**开单前置硬门槛「胜率自估 ≥60%」**（见 `constitution/maker_principles.md` / `agents/risk_agent.md` Gate5）是两个不同阶段，不矛盾：先过 ≥60% 胜率门才允许开单，开单后/合格单之间再按盈亏比为主排序。

## TP（止盈）模型

### TP1（标准止盈第一档）
- **减仓 30%-50%**
- 触发：价格到达计划 TP1 价
- 操作：
  1. 减仓 30%-50%
  2. 剩余仓位止损同时移至开仓均价（保本层）
  3. 进入剩余仓位"防守计划"运行

### TP2 / TP3（防守计划分层）
- 按浮盈防守计划逐层减仓或全部止盈
- 主账户中线最高可达 **5 层**
- Maker 日内通常 **2-3 层**

---

## 浮盈防守层级（图谱第七节）

### Maker 2-3 层

| 层 | 触发 | 操作 |
|---|---|---|
| 第一层（动态止损层） | 价格触及关键位置（如首个 TP 区间附近） | 止损移至近期小时级别极点（低/高点） |
| 第二层（保本层） | 价格进一步向有利方向运动 | 止损移至开仓均价或更优（保本损） |
| 第三层（减仓层，可选） | 价格到达特定 TP 位 | 减仓 30%-50%，剩余按动态防守继续 |

### 主账户 5 层（图谱第十四节）

| 层 | 触发 | 操作 |
|---|---|---|
| 第一层 | 价格触及关键位置 | 设保本损 + 取消所有加仓策略 |
| 第二层 | 价格再进一步 | 止损升级到日线级别极点 |
| 第三层 | 价格触及关键结构未突破反转 | 重设结构性止损 |
| 第四层 | 价格触及 TP1 | 减仓 20%（主账户中线减仓比例小于 Maker） |
| 第五层 | 价格再触及 | 止损升级到周线级别极点 |

## SL（止损）模型

### 硬规则
- **单笔最大亏损 ≤ 3%**（2026.3.5 起，图谱八节）
- 计算：`(entry - sl) / entry × leverage × 100 ≤ 3%`

### 止损位选取
- 左侧入场：挂单区上下极点
- 右侧入场：确认区上下极点
- 主账户中线：结构性止损（迭代更新）

### 止损迭代（仅按防守计划）
- 允许：按防守层级递进升级
- 禁止：擅自移动（V001 违规）
- 禁止：扩大风险
- 禁止：情绪化补仓后改止损

---

## 注意事项 / 取消价格（图谱第七节强制）

### 每笔计划必含
```
注意事项：若价格优先触及 [价格] 则取消此策略
```

### 取消价格选取
- 左侧入场：通常为入场区间反向极点
- 右侧入场：通常为确认信号反向无效价

### 取消触发
- 一旦价格触及取消价 → **无论如何立即取消策略**
- 不允许"再观察一下"
- 已触发未取消 → V012 违规（图谱十三节 2026.4.1 案例）

## 出场决策树

```
持仓中
  ├─ 价格触及取消价？
  │   ├─ 是 → 立即取消（如未开仓）/ 不适用（如已开仓，按 SL 走）
  │   └─ 否
  │       ├─ 价格触及 SL？
  │       │   ├─ 是 → 强制止损（不允许移动）
  │       │   └─ 否
  │       │       ├─ 价格触及第一层防守触发位？
  │       │       │   ├─ 是 → 按层操作（动态止损 / 保本损）
  │       │       │   └─ 否 → 继续持有
  │       │       └─ 价格触及 TP1？
  │       │           ├─ 是 → 减仓 30%-50%（Maker）/ 减仓 20%（主账户）
  │       │           └─ 否 → 等待
  │       └─ 价格触及更高层防守触发位？
  │           ├─ 是 → 按对应层操作
  │           └─ 否 → 继续运行
```

## 与 risk_agent 的协作

risk_agent **Gate 6** 专门校验出场操作：

| 操作 | risk_agent 校验 |
|---|---|
| 减仓 | 是否触发 TP 层？是否到达对应层级？ |
| modify_stop | 是否符合层级递进（保本 → 结构 → 日线极点 → 周线极点）？ |
| close | 是否触及 SL 或 取消价？ |

任何"回退"操作（如已设保本想撤回到结构止损）→ deny。

## 禁止行为

* 禁止止损"扩大"（只能层级递进收紧）
* 禁止主观提前止盈（必须按 TP 层）
* 禁止 TP1 后立即全部清仓（剩余仓位的运行才是关键）
* 禁止取消价被触发后"再观察"
* 禁止主账户中线减仓比例像 Maker 那样大（中线维持稳定）

---

## 核心原则（图谱二十节）

> 出场是比入场更重要的技术。
> TP1 后的剩余仓位运行是关键。
> 第一优先级盈亏比，第二优先级胜率。
