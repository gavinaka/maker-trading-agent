# 入场模型（图谱第六节）

> 本文件定义入场模式的细节规则。
> 与 `risk/entry_exit_rules.md` 互补：本文聚焦"模式"，那边聚焦"决策"。

---

## 两种入场模式

| 模式 | 别名 | 触发逻辑 | 优先级 |
|---|---|---|---|
| **左侧** | 提前限价挂单 | 在目标区间提前挂单，不等 K 线确认 | **主要方式** |
| **右侧** | 价格行为确认入场 | 等待 K 线确认后入场（趋势延续 / 结构突破） | 辅助方式 |

---

## 左侧入场（图谱第六节）

### 执行逻辑
1. 在目标区间**提前限价挂单**
2. **不等待**确认 K 线
3. **接受不确定性**

### 特点
- 优先使用
- 风险：可能被精准止损猎杀（2026.2 曾遭遇多次）
- 适合：盘口分数高 + 结构清晰 + 防守逻辑明确

### 仓位执行
- 标准：**50% 先入 + 50% 等待二次确认**
- 特殊：一次性 100% 入场（仅用于极端强信号，需在备注说明）

### 适用策略类型
- Maker / 左侧 / 高空
- Maker / 左侧 / 低多
- Maker / 左侧 / 反弹空

### 止损位
- 挂单区上下极点
- 必须满足 单笔亏损 ≤ 3%（leverage × 距离 × position）

### 浮盈防守
- 遵循多层结构：动态止损 → 保本层 → 减仓层
- 详见 `risk/floating_defense.md`

### 注意事项
- 必含"取消价格"
- 若价格优先触及取消点 → 立即取消策略
- 已触发取消未取消 → V012 违规

## 右侧入场（图谱第六节）

### 执行逻辑
1. **等待价格行为确认**后入场
2. 适用于趋势延续 / 结构突破确认

### 特点
- 胜率更高
- 入场成本更差
- 适合：盘口分数中 + 结构突破中

### 仓位执行
- 短线为主
- 实时盯盘
- 通常不分批，一次入场

### 适用策略类型
- Maker / 右侧 / 高空
- Maker / 右侧 / 低多
- Maker / 右侧 / 反弹空

### 止损位
- 挂单确认区上下极点

### 浮盈防守
- 遵循多层结构

### 注意事项
- 必含"取消价格"

## 入场模式选择决策树

```
当前评分 ≥ 65？
├─ 否 → 强制观望（不入场）
└─ 是
    ├─ 是否为已认证真极端（C19/C22/C56/C59 候选且整体证据到70）？
    │   ├─ 是 → 推荐左侧（信号强 + 配合强）
    │   └─ 否
    │       ├─ 盘面结构突破中？
    │       │   ├─ 是 → 右侧（等确认）
    │       │   └─ 否 → 左侧（提前布局）
    │       └─ 持仓周期？
    │           ├─ 长持 → 左侧（接受不确定性）
    │           └─ 短线 → 右侧（更精准）
```

## 历史权重监控（图谱十七节 Q3）

review_agent 每日 Q3 跟踪：
- 本日左侧入场笔数
- 本日右侧入场笔数
- 最近 7 日趋势：左→右偏移 / 右→左偏移 / 持平

→ 偏移可能反映：
- 市场结构变化（趋势 vs 震荡）
- 个人心态变化（保守 vs 激进）

→ 周报必须分析此趋势。

## 禁止行为

* 禁止无计划入场（直接 V008 / V013 违规）
* 禁止"看到价格了就先挂着"（不算左侧，算追单）
* 禁止已挂单超时未触发就追加（属于"被动加速"V009）
* 禁止右侧入场后还想"反向追单"
* 禁止入场后立即修改止损（V001 移动止损违规）
