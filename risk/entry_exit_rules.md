# 入场与出场规则

## 入场规则

### 左侧入场（主要方式）
- 在目标区间提前限价挂单
- 不等待K线确认，接受不确定性
- 优先使用
- 风险：可能被精准止损猎杀
- 仓位：按系统分批入场（50%先入，50%等待二次确认或一次性100%入场视情况而定）
- 使用策略类型：Maker / 左侧 / 高空 / 低多 / 反弹空
- 止损：挂单区上下极点
- 浮盈防守：遵循两层防守结构（第一层动态止损 → 第二层保本损）；仓位扣减只发生在止盈档
- 注意事项：若价格优先触及取消点，立即取消策略

### 右侧入场（辅助方式）
- 等待价格行为确认后入场
- 适用于趋势延续或结构突破确认
- 胜率高，但入场成本较差
- 仓位：短线为主，实时盯盘
- 使用策略类型：Maker / 右侧 / 高空 / 低多 / 反弹空
- 止损：挂单确认区上下极点
- 浮盈防守：遵循两层防守结构；第一层止损价只能由成交后后续确认的 4H K 线结构性极点动态确定
- 注意事项：若价格优先触及取消点，立即取消策略

---

## 出场规则

### 优先级
1. 盈亏比（R值，1.5R / 2.5R）
2. 胜率（非核心决策变量，但作为参考）

> ⚠️ 此「胜率非核心决策变量」仅指**离场/选单**的优化优先级，**不等于**入场门槛：开单前置硬门槛「胜率自估 ≥60%」（与总评分≥65 并列）仍须先满足才允许开单。两阶段不矛盾。

### TP1/TP2层级出场
- TP1：默认减仓 50%，剩余仓位继续执行防守计划
- TP2：清理剩余仓位
- 剩余仓位：动态管理，第一层只移至成交后后续形成并确认的 4H 极点，第二层只设保本损

### 注意事项
- 每笔计划必须有明确取消价格
- 若价格优先触及取消价格，立即执行策略取消
- 不得因为个人判断擅自修改入场或出场
- 所有执行必须遵循每日Plan、风控检核及状态门禁
