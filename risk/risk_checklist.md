# 风控检核清单（图谱第四节，7 项硬规则）

> 开仓前必须**全部 7 项 ✓** 才允许执行。
> 任一缺项 → 计划质量评级"**低**" → V002 违规风险 → 不计入洁净样本。
> 第 7 项（单笔 3%）从 **2026.3.5 起**正式加入。

---

## 检核清单

```
- [ ] 1. 是否记录交易计划
- [ ] 2. 是否符合风险敞口要求
- [ ] 3. 是否完成技术面确认
- [ ] 4. 是否设置好止损止盈
- [ ] 5. 是否在规定交易时间内
- [ ] 6. 是否严格按入场信号执行
- [ ] 7. 单笔止损 ≤ 3%
```

---

## 每项详细判定

### 1. 是否记录交易计划

**判定**：
* `outputs/<today>_maker_morning.md` 或 `_maker_evening.md` 中含 `[有计划]` 段
* 计划必含：方向 / 价格区间 / 仓位 / 入场方式 / 止盈 / 止损 / 浮盈防守 / 取消价格
* 缺任一字段 → 第 1 项 ✗

**禁止**：临时开仓无计划（V002 / V008 / V013 违规）

---

### 2. 是否符合风险敞口要求

**判定**：
| 标的 | 账户 | 单笔区间 USD | 杠杆 |
|---|---|---:|---|
| BTC | Maker | $500 - $1000 | 5x |
| ETH | Maker | $300 - $800 | 5x |
| BTC | Main 中线 | $2000 - $4000（分批构建总额） | 5x |

* `request.size_usd ∉ 区间` → ✗
* `request.leverage != 5` → ✗（除非用户在 metadata 明确 override 且情绪/状态全绿）
* Maker 单日交易数 > 3 → ✗

**数据源**：`state/maker_state.json.position_rules` + `main_account_state.json.risk_management`

---

### 3. 是否满足开单双门槛（总评分 + 胜率）

**判定**（两门槛并列·任一不过即不开）：
* 门槛① `state/score_state.json.current_score.total_score >= 65`（盘口 70 只允许 C19/C22/C56/C59 经整体证据确认为真极端）AND
* 门槛② `plan.win_rate >= 60`（胜率自估 ≥60%·2026-06-16 升级为硬门槛）AND
* `outputs/<today>_footprint_<HHMM>.json` 存在且 `data_quality != "partial"`

**禁止**：评分未达 65 或 胜率未达 60% 强行开仓（V004 / V011 违规）；用执行概率 <50% 否决开仓（执行概率为软参考·非门槛·只调挂价）。

---

### 4. 是否设置好止损止盈

**判定**：
* `request.sl > 0` AND `request.tp > 0`
* **R:R ≥ 1:2.5**：`abs(tp - entry) / abs(entry - sl) >= 2.5`
* Maker TP1/TP2 必填：TP1 默认减仓 50%，TP2 清剩余仓位
* Maker 浮盈防守计划 ≥ 2 层：第一层只写触发价 + 成交后后续确认的 4H 极点规则，禁止预填极点止损价；第二层只设保本损
* 取消价格必填

---

### 5. 是否在规定交易时间内

**判定**（GMT+8 北京时间）：
* 早间执行窗口：**09:00 - 12:00**（早间计划生效）
* 晚间执行窗口：**19:00 - 22:00**（晚间计划生效）
* 午盘观察期：**14:00 - 18:00** → 减少新开仓
* 其他时段 → ✗

**例外**：C19/C22/C56/C59 真极端已认证 + 用户在 metadata 标 `time_window_override:true`

---

### 6. 是否严格按入场信号执行

**判定**：
* 当前价 ∈ 计划入场区间 ±0.5%
* 入场方式（左/右侧）与计划一致
* 分批比例符合计划（标准 50%+50%，特殊 100%）

**禁止**：
* 未击中入场点强行追单（V014 违规）
* 提前进场（FOMO）
* 修改入场方向

---

### 7. 单笔止损 ≤ 3%（2026.3.5 起硬规则）

**判定公式**：
```
单笔风险 % = (|entry - sl| / entry) × leverage × 100

判定：单笔风险 % ≤ 3
```

**举例**（5x 杠杆）：
* entry = 70000, sl = 70420 → (420/70000) × 5 × 100 = 3.0% ✓ 边界
* entry = 70000, sl = 70500 → (500/70000) × 5 × 100 = 3.57% ✗

**禁止**：
* 任何情况下扩大止损区间（V001 移动止损违规）
* "再观察一下"延后止损
* 情绪化补仓（V004）

**理由**（2026.3.5 笔记）：
> 小资金阶段用 2-3% 止损
> 不是为了激进
> 而是为了在可控风险下加快复利

## 整体校验逻辑

```python
risk_checklist_pass = all([
    item_1_plan_recorded,
    item_2_risk_exposure,
    item_3_market_confirmation,
    item_4_sl_tp_set,
    item_5_in_time_window,
    item_6_strict_signal,
    item_7_single_loss_under_3pct
])

if not risk_checklist_pass:
    decision = "deny"
    plan_quality = "低"  # 触发 V002 类违规
```
