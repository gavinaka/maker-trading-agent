一·补、框架优先级（三层权重按账户分流）（2026-05-31 用户拍板）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

三层 = 盘口（footprint/资金流）/ 盘面（日·周·月趋势结构）/ 基本面（BlockBeats）。
**权重顺序随账户角色翻转，不可混用：**

  ┌────────────────────┬──────────────────────────────┐
  │ 日内 Maker 交易      │  盘口 > 盘面 > 基本面          │
  │ 中线计划（主账户）   │  基本面 > 盘面 > 盘口          │
  └────────────────────┴──────────────────────────────┘

【日内 Maker：盘口 > 盘面 > 基本面】
  - 方向盘 = 盘口（footprint 16 组合 / 70 分）；盘面（30 分）确认入场位置。
  - 基本面权重最低，**不参与方向打分**，只起两个作用：
      (a) 风险否决：重大政治/宏观突发 → 强制观望（呼应"重大新闻强制观望"）；
      (b) 与盘口方向冲突 → 降低信心/降频，但不得据基本面反向。
  - 一句话：基本面对 Maker 只能"踩刹车"，不能"打方向盘"。

【中线计划（主账户）：基本面 > 盘面 > 盘口】
  - 方向盘 = 基本面（且内部"政治 > 行业"，见 BlockBeats 规则），决定中线大方向。
  - 盘面（日/周/月趋势结构）= 决定入场区与分批 4 档位置。
  - 盘口权重最低，仅作择时微调，**禁止据盘口短期背离推翻中线大方向**。
  - 一句话：中线方向盘在基本面手里，盘口只是中线进出场的择时辅助。

⚠️【当日 Maker 交易的宪法两层门禁（2026-05-31 用户拍板）】
  ┌──────┬──────────────────┬────────┬──────────────────────────┐
  │ 层级  │ 字段              │ 谁填    │ 含义                      │
  ├──────┼──────────────────┼────────┼──────────────────────────┤
  │ 第一层│ 门禁（开仓前状态）│ 用户填  │ 今天能不能交易（主观/状态）│
  │ 第二层│ 不能做（方向）    │ 系统填  │ 今天禁哪个方向            │
  └──────┴──────────────────┴────────┴──────────────────────────┘
  - **门禁=用户填**：第一优先级主观判断（情绪/节奏/身体），**agent 算不了**，系统只读取，不替判、不过度设计。门禁=不可交易 → 硬停，今日不写任何计划。
  - **不能做=系统填**：由**系统**通过当天数据分析推导（日内 Maker = 盘口>盘面>基本面 = "禁止追当下最拥挤的一边"，详见 §2.5 + `cannot_do_mapping.md`）。
  - **"回填"含义**：plan 写到最后、经数据分析后**填出不能做**（= 分析的收口结论），**不是**"全天交易做完后"才补。
  - **不能做是决定当日 Maker 交易方向的标准，宪法级**（risk_agent Gate3 第二层方向门禁，无 override）。
  - **归属**：「不能做」是**当天 Maker**字段，与中线/主账户大方向无关，二者不混淆（中线与 Maker 互不干扰）。

注：现行评分（盘口70+盘面30，基本面在分外作否决）即"日内 Maker"口径的落地。
