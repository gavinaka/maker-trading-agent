# 交易复盘与闭环体系

# 日复盘结构
每日23:00前完成复盘。

## 五个核心问题
### 1. 执行日内交易
* 计划完成度X%

### 2. 交易循环完成情况
* 已开单
* 未开单
* 执行了X笔

### 3. 左侧交易向右侧交易权重偏移
* 描述变化

### 4. 心力控制
* 工作及生活影响程度

### 5. 中线之扁
* 中线仓位状态总结

# 总结
记录当日核心体会与心得。

# 日复盘核心原则
* 强调过程质量评估
* 不依赖结果
* 追踪左右侧入场风格变化
* 记录情绪状态与生活影响
* 即使未开单也必须填写
