# 胜率判断口径分析（2026 年 55 样本倒推）

> 目的：胜率本轮升级为开单硬门槛（≥60%）且由系统自估。本报告倒推用户今年真实样本，提炼"用户如何判胜率"，供系统自估校准、提升一致性。
> 数据源：交易Plan Maker（胜率落点）+ 交易Plan 主账户（日内价格行为分析）逐日配对。
> 范围：2026 年 1–5 月 Maker「汇总」库全部**有胜率的交易日 = 55 个样本**（另有 64 个观望日无胜率）。6 月条目仅为 child_page、未入汇总库，未纳入本批。
> 性质：**纯分析报告·未改任何系统逻辑文件**（用户指定"先只出分析报告"）。

> 🟥🟥 **口径订正横幅（2026-06-17 用户两次拍板·凌驾本文下方旧结论）**：本文下方"胜率只有70/75/80三档·实际开单从不<70·自估<70即观望·确信底就是70"等**派生规则已被推翻**。**现行权威口径＝门槛② 胜率自估 ≥60% 即可；胜率取真实估值——实际多少就多少（如 62/65/68%…均合法），不锁固定档、无"<70即观望"判停**（权威 `scoring/winrate_methodology.md`）。下表 70/75/80 的样本分布仅为**用户历史填写习惯的factual快照**（历史确实多落整数档），保留作估算质量参照、**不再是允许值清单或 floor**。

## 1. 胜率词汇与分布（关键事实）

| 胜率档 | 样本数 | 占比 |
|---|---|---|
| 70% | 29 | 52.7% |
| 75% | 13 | 23.6% |
| 80% | 13 | 23.6% |
| <70% | 0 | 0% |

- 🔑 **实际开单样本胜率从不低于 70%**，只用 70/75/80 三档（晚间高确信反转单偶见 85%，如 5.18 晚反弹空）。
- 🔑 **<70 确信度 = 不开单（进观望）**。64 个观望日的措辞反复出现"**胜率及盈亏比不符合系统要求**"（如 1.9 / 1.13 / 2.1 / 2.27 / 4.1）。即胜率达不到 ~70 档即弃权。
- 含义：胜率硬门槛 ≥60% 在用户真实口径里**几乎永不卡单**（开单确信底就是 70）；门槛的真实作用＝**确信度地板**——系统自估达不到"70 档质量"就该落观望、不开。

## 2. 胜率 = 前瞻确信度分级（非回测命中率）

- 胜率是**开仓前对该笔计划的主观确信度**（plan-time forward estimate），不是统计学回测胜率。系统要复刻的是用户这套**确信度评级逻辑**，不是去算真实命中概率。
- **三轴分离**（与本轮门槛重构一致）：
  - **胜率**＝设置质量/确信度（开单硬门槛）。
  - **执行概率**＝价格可达性（软参考）。同一胜率档执行概率 50%–80% 都有（5.28 胜率80/执行50；1.13 胜率80/执行70），证实两轴独立。
  - **盈亏比**＝独立要求（恒 ≥1:2.5，高确信单常见 1:3 / 1:3.5）。

## 3. 三档驱动 rubric（倒推归纳）

驱动胜率分档的两大主因：**① 盘口信号确认强度（背离/极端 > 中性）　② 结构位质量（多重共振关键位 > 普通边缘）**。盈亏比、顺/逆势为次因。

### 70%（baseline·达标确信底·占 53%）
- **盘口解读 = 中性 / 中性偏多 / 中性偏空，无明确背离**（绝大多数 70 档样本解读为"中性"）。
- 共振结构达标 + R:R≥1:2.5 + 合理边缘，即"达标即可开"的标准单。
- 例：3.18 高空（解读中性·多头趋势短线）、2.18 低多（中性·空头趋势）、1.16 回调多（中性·多头中线）、5.6 高空（中性·多头单边逆势→确信仅给底档）。

### 75%（中等加成·占 24%）
- 在 70 基础上**多一项确认**：出现**小幅背离 / 4H 级别背离**，或**结构位质量更高 / 盈亏比更高（1:3、1:3.5）**，但信号未达极端。
- 例：5.11 高空（看跌背离 4H）、2.13 做多（持续看涨背离）、4.1 低多（小幅看涨背离）、1.7 高空防守（小幅看跌背离·R:R1:3.5）、2.25 高空（强压反弹拿空头流动性·R:R1:3）。

### 80%（高确信·占 24%）
- 满足以下**任一强确认**：
  - **明确背离 / 极端组合 / 盘口预警**：5.28 利空看跌背离**极端组合**、5.12 看跌背离(4H)、3.6 CVD 背离、1.13 CVD 看涨背离预警。
  - **多重强共振关键结构位**：4.20 周线 W 底区间顶部共振支撑·接飞刀低多、3.30 关键多头防守极限区 65000-65500 回调多、2.4 CME 缺口+区间下轨反弹需求明显（左侧）。
  - **顺势反弹空挂强压 + 高 R:R**：3.22（R:R1:3）、3.13（R:R1:3）、5.31、4.27。
- 即**信号与结构双重强确认**时给最高档。

### <70 → 观望（不开单）的触发口径
- 盘口模糊/纯中性无确认 + 无高质量边缘；高波动率/数据公布前不确定（CPI/非农/利率决议）；盈亏比不足；超跌需盘面修复未企稳。
- 统一措辞："胜率及盈亏比不符合系统要求""不符合 Maker 系统逻辑"。

## 4. 其它观察（次因·弱相关）

- **左/右侧与胜率不强相关**：各档左右都有。左侧接飞刀/回踩低多也能到 80（4.20），右侧反弹空也能到 80（5.28）。
- **盈亏比与胜率弱正相关**：80 档更常见 1:3 / 1:3.5。
- **顺/逆势**：逆势单（如多头单边里高空 5.6）确信偏低给 70；顺势 + 背离确认给高档。
- **策略类型分布**：高空/低多/反弹空/回调多/做多/做空均覆盖，胜率不由策略类型直接决定，而由该类型当下的信号+结构质量决定。

## 5. 对"系统胜率自估"的校准建议（供后续落地，本报告不实施）

系统自估胜率应按下表，与用户口径对齐：

| 系统自估 | 触发条件（与盘口/盘面评分体系挂钩） |
|---|---|
| **<70 → 观望** | 盘口纯中性无背离 + 无高质量边缘 / 高波动事件前 / R:R<2.5 / 结构未企稳 |
| **70** | 共振达标 + 盘口中性档（无背离）+ R:R≥2.5 + 合理边缘 |
| **75** | + 小幅或 4H 背离，或更高质量结构位 / R:R≥1:3 |
| **80** | + 明确背离/极端组合(C01/C02)/盘口预警，或多重强共振关键防守位 |

- 与现有体系的接口：盘口"极端候选 70/60"与"中性/背离"解读、盘面"结构位质量/共振"已是现成输入，胜率档可由这些因子映射，无需新数据源。
- 与门槛体系一致：自估 ≥60%（实际落 70/75/80）→ 过胜率门槛；自估 <70 → 观望。**这把"胜率硬门槛"从一个空泛数字落成可复算的三档 rubric**。

## 6. 重要 Caveats（准确性铁律）

1. **前瞻 vs 实际**：本批是 plan-time 自估确信度，**未交叉实际成交结果（交易Check）**。要做"自估 vs 真实命中"的二阶校准，需再读对应交易Check 的成交/盈亏，单独一轮。
2. **75/80 边界含主观成分**：两档都属"有额外确认"，分界由用户综合定；rubric 抓主因，不宜过度公式化（防走极端）。
3. **样本范围**：1–5 月 55 个；6 月未入库未纳入。结论基于这 55 个，后续可纳 6 月+实际结果增强。
4. 本报告为观察归纳，落地为系统逻辑前应经用户确认。
