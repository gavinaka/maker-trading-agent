## 二、八条优化（现状问题 → 样本证据 → 优化后逻辑）

### ① 【头号】「不能做」字段：从「机械抄 state 持仓方向」改为「禁止追当下最拥挤的一边」
- **现状问题**：我把 `cannot_do` 渲染成 state 里的持仓方向（5/29 持多→写"做多"）。这是 context_log 反复记的头号分歧，现在 17 天样本判定它**系统性错误**。
- **样本证据**：用户的「不能做」从不等于持仓方向，而是一条**反人性的动态约束**——禁止去追"刚走完那段行情 / 当下最拥挤"的方向：
  - 多头单边延伸中(价已大涨) → **不能做=做多**（5/6-5/15 连续 8 天）
  - 破位下行初期 / 价到支撑且现货托底 → **不能做=做空**（5/1、5/18）
  - 空头延续到需求区 / 震荡 → **不能做=追多空 / 追空**（5/19-5/29）
  - 出背离时背离优先：看涨背离=空头拥挤→**别做空**(5/1)；看跌背离=多头拥挤→**别追多**(5/11-12)
- **优化后逻辑（可直接编码的推导树）**：
  1. 若盘口/盘面出现**背离** → 禁止追"被挤压"的拥挤侧（看涨背离→禁做空；看跌背离→禁做多）。
  2. 否则按**趋势阶段 + 价格相对支撑/压力位置**：
     - 多头单边 且 价偏上沿 → 禁「做多」
     - 空头/破位 且 价偏下沿(近支撑) → 禁「追空」
     - 震荡 → 禁「追多空」
  3. 「追」前缀：行情已延伸 / 进入震荡时加（区别于趋势刚启动时的"做空/做多"）。
- 这条**不依赖持仓**。跑报告前仍须先读 Notion 交易Check 校准持仓（5/29-30 用过期 short 失真的教训），但 `不能做` 不再由持仓推导。

### ② 基本面：从「数头条做利空/利多计数」改为「单一主线 + 兑现状态机」
- **现状问题**：我用 news_agent 把多条快讯聚合成 sentiment 差值（利空数−利多数<2→中性），导致 5/29 我=中性偏空(机构存币+鹰派)、用户=利多(美伊主线)。
- **样本证据**：17 天**每一天**的基本面都锚定**同一条主线=地缘政治(美伊/全球化博弈)**，并带一个 **价格{已/未/部分}兑现** 标签。次要新闻只作修饰，不参与"计数"。
- **优化后逻辑**：基本面段先**锁定当期唯一主线叙事**，方向由主线进展决定，其余新闻仅作 modifier；**必须输出「价格{已/未/部分}兑现」**（我现在完全漏掉这个字段）。news_agent 的计数法降级为"次要新闻情绪参考"，不再直接定调。

### ③ 盘口解读：在 16 组合标签之上叠加「燃料 / 流动性 / 现货-合约分歧 / 斜率比较」叙事 + 标注时间框架
- **现状问题**：我只输出 16 组合查表标签（如"末期出货"）。
- **样本证据**：用户解读用**斜率比较**（5/26"价升斜率>CVD升斜率→中性偏多"）、**燃料语言**（"空头燃料持续流入/多头燃料消耗"）、**流动性**（"空头流动性拿取90%以上""现货承接极弱托底极低"）、**现货 vs 合约分歧**，且**标注背离的时间框架**（"看跌背离(4小时级别)"）。
- **优化后逻辑**：保留 16 组合作 base label，`解读` 行追加 燃料/流动性/现货-合约 一句话叙事，并对背离标注时间框架。

### ④ 盘面：固定「日线 + 小时」两层，每层以单字结论收口，统一词汇表
- 已知两层（SOP 已记）。本次确认**每层固定以「中性/利空/利多」单字结论收尾**，词汇表固定：
  - 日线层：SMA20/SMA200、上行平行通道上轨/中轨、FVG/CME缺口、吞没/M顶/双顶、区间(如76-79k)、量价/CVD背离
  - 小时层：趋势延续/转震荡、更低低点·更高高点、流动性拿取/拋压、需求区、关键价位是否有效跌破
- **优化后逻辑**：模板强制两层各自一句结构描述 + 一个单字结论；杜绝写成"盘面·15m级别"(15m 只属第⑤源 TradingView 执行 Check)。

### ⑤ 趋势确认：带时间限定词，并显式给出「转换链」位置
- **样本证据**：趋势恒带 (短线)/(单边)/(中短线)；月内有清晰转换链 多头单边→震荡→空头(短)→震荡。
- **优化后逻辑**：`趋势确认` 不只给标签，注明当前处于转换链哪一环（"由多头单边转震荡第N日""空头延续放缓"），帮助判断 ① 的"追"前缀。

### ⑥ 主账户策略段 = 中线计划「防守层状态机」，跑报告前强制校准持仓
- **样本证据**：主账户是**单一中线仓**，策略行几乎恒为「中线计划保持不变/无迭代」，偶发事件=迭代止损(5/1→78900)、降成本(5/8)、**新增第五层防守(5/21,触76000止损设周线极点)**、**止盈出局(5/27)**、5/28 反手做多@73,500(底仓30%)。
- **现状问题**：5/29-30 报告主账户段用了过期 short@79150(+35%) → 失真。
- **优化后逻辑**：① 跑报告**第一步**读两库交易Check 取最新持仓(created_time desc)，禁止沿用上次 state；② 策略段按"中线计划{保持/迭代/新增防守层/止盈出局} + 当前仓位% + 防守层级"状态机输出。

### ⑦ 支撑/压力恒为「区间」，宽度约 300-500 点，日内级别
- **样本证据**：17 天全部是 XXXXX-XXXXX 双区间，宽 300-500。
- **优化后逻辑**：永远输出区间不输出单点；与盘面"需求区/强压区"措辞一致。

### ⑧ 接入「门禁 / 心力」前置硬过滤 + 用 Maker 真实分布校准期望
- **样本证据（门禁/心力）**：5/25 身体疲惫→**不可交易**(休市)；5/21 团建环境干扰→**心力收缩机制**(专注0/消耗10)；5/14 喝酒疲惫仍可交易；5/7 连续止损=1(<3 仍可)。这些是**评分之外的可交易性闸门**，我现在的报告完全没接入。
- **样本证据（Maker 真实分布）**：14 笔→成交 9 / 取消 5；成交 9 笔=盈 2 / **保本 5** / 亏 2，**7/9 不亏**，亏损均 ≤3%。系统的 edge 是**资金保全**(防守层"保本出局"占主导)，不是高胜率。
- **优化后逻辑**：
  - 报告生成前读 `开仓前门禁`+`心力监控`：若当日"不可交易"或"收缩机制"，**无视评分直接观望/降频**，并在报告注明原因。
  - Maker 段框架始终带 **取消价 + 防守层**（这是 edge 所在；对照实验 #6 也指出我常停在"条件描述"不到可执行单粒度）；期望管理上把"保本出局"视为成功而非失败。

## 三、落地建议（尊重对照实验「满 20 次再改」纪律）

对照实验的本意是"别因**单日 n=1 分歧**就过拟合改流程"。本分析基于 **17 天用户自身书写**归纳方法论，不属于单日反应，但仍建议分级落地、由用户确认：

- **建议立即落地（属"修 bug / 补字段"，非改判断口径，风险低）**：
  - ① 不能做改为推导树（停止机械抄持仓方向）——这是明确错误
  - ⑥ 跑报告先读交易Check 校准持仓（已是教训）
  - ② 基本面补「价格兑现」字段、⑦ 支撑压力强制区间、④ 两层各自单字结论收口——纯格式/字段对齐
  - ⑧ 接入门禁/心力前置硬过滤——安全闸门
- **建议先观察、满 20 次对照再定（涉及判断口径，可能过拟合）**：
  - ② 基本面"主线锚定"是否完全取代计数法
  - ③ 盘口"燃料/流动性"叙事的具体措辞与权重
  - ⑤ 趋势"转换链"判定颗粒度
  - 盘口/盘面打分校准（5/29 观察到我 SMA20 偏热约 3 分）
