{{当日核心体会 / 心得 1-3 句}}

## 字段来源

| 字段 | 数据来源 / 计算方式 |
|---|---|
| 早间计划状态 | `outputs/<today>_maker_morning.md` 解析 `[观望]` 或 `[有计划]` |
| 晚间计划状态 | `outputs/<today>_maker_evening.md` 解析 |
| 实际执行笔数 | `outputs/<today>_check_records.json` 数组长度（status != "未开仓"） |
| 计划笔数 | maker_morning + maker_evening 中"有计划"段数量 |
| 笔详情 | `check_records[]` 各字段 |
| 左/右侧统计 | `check_records[].entry_type` 计数 |
| 最近 7 日趋势 | 读 `reviews/<最近 6 天>.md` 中"3. 左右侧"段做趋势对比 |
| 工作/生活影响 | 用户输入（review_agent 询问） |
| 情绪事件 | `outputs/<today>_emotional_log.json.self_reported.free_text` |
| 状态门禁触发次数 | `state/risk_state.alerts` 当日条目数 |
| 中线持仓详情 | `state/main_account_state.json.position_status` |
| 当前防守层级 | `state/main_account_state.json.mid_term_structure.current_defense_layer` |
| 今日是否迭代 | 比对 `main_account_state.last_update` 与昨日 archive |
| 总结 | 用户输入（**禁止 AI 生成**） |

## 渲染规则

1. **每日必填**——即使未开单也要全部 5 个问题答完
2. **总结禁止 AI 生成**——必须用户输入，不允许 review_agent 自动写
3. **数字必须精确**——浮盈浮亏需有具体数字（即使是估算），不允许"少量"/"约略"
4. **总结禁止口号化**——禁止"继续努力"/"加油"等空话，必须基于当日具体事件
5. **状态门禁触发数 ≥ 1**——必须在备注解释具体哪项触发
6. **连续观望 ≥ 5 天**——总结段必须分析原因，避免系统性问题
