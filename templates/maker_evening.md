# Maker 晚 20:30 新增计划模板（图谱第十一节）

> 由 `agents/output_agent.md` 渲染，时段：20:00 - 20:30
> 在早间盘前的基础上**新增**或**修订**Maker 计划。
> 不替换早间内容，是叠加。

---

## 模板

```
【晚20:30新增计划】{{YYYY-MM-DD}}

不能做：{{追多空 | 做多 | 做空}}    ← 当天 Maker 市场推导（晚盘行情更新可能与早间不同；非主账户）

BTC（策略）：[观望 | 有计划]
  {{同 maker_morning.md 格式}}
```

---

## 关键差异（与早间相比）

| 差异点 | 早间 | 晚间 |
|---|---|---|
| 数据时点 | 11:00 评分 | 20:00 评分 |
| 模板字段 | 无"不能做"段 | **含"不能做"段**（独立于主账户日报） |
| 触发时机 | 链 A 第 7 步 | 链 B 第 5 步 |
| 文件输出 | `outputs/<today>_maker_morning.md` | `outputs/<today>_maker_evening.md` |
| 桌面合并 | `_交易计划.txt` 第二段 | `_交易计划.txt` 第三段（追加） |

---

## 字段来源

与 `templates/maker_morning.md` 完全相同，**但读取的是 20:00 重新评分后的数据**：
* `state/score_state.json` 必须在 20:00 ± 30 分钟内更新
* `state/session_state.json.tasks.score_updated_evening == true`
* `outputs/<today>_footprint_2000.json`（或最近一次 20:00 后的 footprint）

## 示例：观望

```
【晚20:30新增计划】2026-05-29

不能做：做多

BTC（策略）：[观望]
  理由：
    - 20:00 重评分总分 55，仍未达 70 门槛
    - 盘面分上升至 18（支撑结构改善），但盘口仍 37（CVD 横盘）
    - 主账户限制方向不匹配

  执行概率：0%
  注意事项：保持观望至次日早间，明日 11:00 重评分
```

## 示例：有计划

```
【晚20:30新增计划】2026-05-29

不能做：做多

BTC（策略）：[有计划]
  执行概率 65% 胜率 70%（已执行 22%）
  反弹空：69200-69500 持仓 600 刀 [OKX] 左侧 盈亏比 1:2.8
  止盈：67800（TP1）减仓 50%
  止损：69900
  浮盈防守计划：
    第一层：价格触及 68500 → 止损移至 69200（开仓均价）
    第二层：价格触及 67800（TP1）→ 减仓 50%，剩余仓位止损移至 68000
  注意事项：若价格优先触及 69900 则取消此策略
```

---

## 渲染规则

1. **"不能做"字段强制**——晚间模板独立出现，不可省（即使与早间相同也要重申）
2. **20:00 评分必须新鲜**——超过 6 小时则拒绝渲染（按 freshness_rules.md）
3. **可与早间计划共存**——若早间已有计划且仍有效，晚间可标"早间计划继续有效，无新增"
4. **二次取消价格**——晚间新计划的取消价不可与早间冲突；若与早间持仓矛盾，必须先取消早间
