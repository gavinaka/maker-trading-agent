## 字段来源

| 字段 | 来源 |
|---|---|
| 本金 | 用户本周确认，或 Notion 当前行中有时间戳的明确值 |
| 现有资金 OKX/Binance | 用户本周确认或 Notion 当前行；本地 state / 旧周报不得补值 |
| 同比上周 | 与 `reviews/<上周>_weekly.md` 对比 |
| Maker 笔数/胜率/盈亏 | 本周 Notion Maker Check 当前行；这是实际执行指标，不是日报预测准确率 |
| 中线持仓 / 当前防守层级 | 周末 Notion 当前行或用户确认 |
| 本周迭代 | 本周期已交付变更与用户确认 |
| 累计 PCT（从开仓起） | 经确认的均价、当前价和杠杆，由确定性计算重算 |
| 洁净样本累计 / 本周新增 | Notion 系统50笔当前行与当周记录 |
| 违纪笔数/类型 | Notion 违规/惩罚当前记录或本周期哈希绑定违规记录 |
| 核心迭代 | 用户输入（review_agent 询问） |
| 核心洞察 | 用户输入（review_agent 询问） |

## 历史财务参照

历史余额不再嵌入活模板。需要同比时，只读取上一份已验证周报的对应值，并与本周用户确认/Notion 当前值比较；跳变必须要求用户确认。

---

## 渲染规则

1. **必须周日 22:00 后生成**（图谱第十七节）
2. **核心迭代 / 核心洞察禁止 AI 生成**——必须用户输入
3. **数字必须精确到美元**——禁止"约略"/"大概"
4. **关键词命名传承**——默认沿用最近，特殊节点用户手动
5. **资金跳变 > $200**——发起 alert，由用户确认是误填还是真实
6. **洁净样本进度强制**——本周如有违纪笔，必须列出类型 ID（V_NNN）
7. **数据边界与来源**——正文必须列统计窗口、Notion/用户确认时间、未知项；不得出现外置准确性评估指标
