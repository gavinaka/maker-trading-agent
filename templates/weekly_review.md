## 字段来源

| 字段 | 来源 |
|---|---|
| 本金 | 固定 $1200（图谱十九节历史财务数据） |
| 现有资金 OKX/Binance | 用户输入（review_agent 询问当周日实际余额） |
| 同比上周 | 与 `reviews/<上周>_weekly.md` 对比 |
| Maker 笔数/胜率/盈亏 | 聚合 `outputs/<本周 7 日>_check_records.json` 中 account=="maker" |
| 中线持仓 | `state/main_account_state.json.position_status` |
| 当前防守层级 | `state/main_account_state.json.mid_term_structure.current_defense_layer` |
| 本周迭代 | 比对 7 日内 `main_account_state.last_update` 历史 |
| 累计 PCT（从开仓起） | 持仓均价 vs 当前价 × 杠杆 |
| 洁净样本累计 | `state/maker_state.json.clean_sample_system.current_progress_pct` × 50 |
| 本周新增洁净 | 当周 check_records 满足洁净条件的数量 |
| 违纪笔数/类型 | `governance/violations/<本周 7 日>_*.json` 聚合 |
| 核心迭代 | 用户输入（review_agent 询问） |
| 核心洞察 | 用户输入（review_agent 询问） |

## 渲染规则

1. **必须周日 22:00 后生成**（图谱第十七节）
2. **核心迭代 / 核心洞察禁止 AI 生成**——必须用户输入
3. **数字必须精确到美元**——禁止"约略"/"大概"
4. **关键词命名传承**——默认沿用最近，特殊节点用户手动
5. **资金跳变 > $200**——发起 alert，由用户确认是误填还是真实
6. **洁净样本进度强制**——本周如有违纪笔，必须列出类型 ID（V_NNN）
