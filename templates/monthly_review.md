## 字段来源

| 字段 | 来源 |
|---|---|
| 本金 | 固定 $1200 |
| 现有资金 | 用户输入（月末余额） |
| 净亏损总额 | $1200 - 现有合计 |
| 同比上月 | 与 `reviews/<上月>_monthly.md` 对比 |
| 持仓详情 | `state/main_account_state.json` + `state/maker_state.json` |
| Maker 策略笔数/胜率/盈亏 | 聚合本月所有 `outputs/<日期>_check_records.json` |
| 中线持仓天数 | `position_status` 持仓开始日至月末 |
| 防守层级演变 | 比对月初/月末 `mid_term_structure.current_defense_layer` |
| 违规笔数 | 聚合 `governance/violations/<本月>_*.json` |
| 洁净样本累计 | `state/maker_state.json.clean_sample_system.current_progress_pct` × 50 |
| 核心问题复盘 | 用户输入 + review_agent 提供"本月 4 个周报的核心洞察"作为线索 |
| 下月目标 | 用户输入（**禁止 AI 生成**） |

---

## 渲染规则

1. **月末最后一天 23:00 触发**——错过当日不允许"补做"
2. **整月问题复盘 ≥ 3 条**——不足则用户必须补
3. **下月目标具体可执行**——禁止"提高水平"/"减少违规"等空话；必须含数字或动作（如"完成 5 笔洁净样本"）
4. **违规聚合按等级分类**——便于趋势分析
5. **3 个月趋势对照强制**——历史财务表必填
