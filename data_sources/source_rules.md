# 数据源执行规则

# 核心原则
数据真实性高于输出完整性。

---

# 强制规则

## 规则1
禁止在数据缺失情况下主观推理补全。

## 规则2
无法访问网站，必须明确输出“数据源无法访问”。
禁止：
- 编造数据
- 使用旧数据替代
- 使用历史缓存

## 规则3
读取失败，必须停止对应模块输出。
例如：
- CVD读取失败
- 资金费率失败
- BlockBeats失败
- Farside BTC ETF Flow 读取失败或 `latest.total_usd_m` 非数值

则该模块标记“待补充”。

## 规则4
禁止混淆时间周期。
例如：
- 日线数据
- 小时数据
- 实时盘口

必须明确区分。

## 规则5
所有方向判断必须基于真实数据。
禁止：
- 猜测方向
- 猜测结构
- 猜测趋势

---

# 新闻规则
BlockBeats 必须截图。
禁止：
- AI总结替代截图
- 伪造新闻
- 用历史新闻代替当日新闻

---

# 输出优先级
正确性高于完整性。宁可缺失，不能伪造。

---

# 数据异常规则
发现以下情况：
- 网站无法访问
- 权限不足
- 页面结构变化
- 数据为空
- API异常

必须停止生成对应数据。

---

# Agent行为限制
Agent 不是分析师。Agent 是规则执行器。

---

# 禁止行为
禁止：
- 擅自修改规则
- 擅自提高评分
- 擅自补全缺失字段
- 擅自生成不存在的数据
- 使用模糊描述替代真实数据
