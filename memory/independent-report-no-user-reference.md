跑日报（早间/晚间）时，**系统报告的所有判断字段必须是我从五源+评分体系独立推导的结果**，禁止参照用户手写日报里的判断。

**禁止用作输入/参照的（用户手写"日报判断"）**：
- Notion（主/Maker）交易Check 计划页里的「不能做」「基本面方向」「趋势」
- 用户当日手写的开仓计划（方向/入场区/止盈/止损/反弹空 等具体单），包括"未开仓"的挂单计划——那是用户的判断与决策。

**仍可作事实输入的（非判断）**：
- 实际已开仓位（状态=持仓中/已平仓 的真实持仓——这是客观状态校准，见 [[notion-positions]] 用途）。
- 「开仓前门禁」「心力监控」行（不可交易/收缩机制 等操作性硬过滤——决定今天能否交易，不是市场判断）。
- TradingView 图上的手绘支撑/压力/通道线（这是指定的第⑤数据源本身，不是手写日报）。

**Why**：用户要的是一份独立的系统稿，让我的判断与他的判断可以事后客观对照、互为校验；若我出稿前先看了他的答案，稿子被污染，对照失去意义，我也学不到自己的盲点。

**How to apply**：
1. 出稿过程中不读、不引用用户手写判断页的判断字段；即便已无意读到，也不得让其影响或"对齐"我的结论。
2. 报告里禁止出现「与用户手写一致／印证用户」之类对照语——我只陈述自己的推导。
3. 我的「不能做」「方向」「Maker 入场区/止盈止损」全部自推；结论与用户偶然相同没关系，但推导链必须是我自己的。
4. 任何对照只能**事后**做（我独立成稿之后），且仅在用户明确要求时；对照实验 [[report-comparison-experiment]] 的"观察用户手写"做法据此作废——改为出稿后对照。
